    ① 怎么把它叫出来

    两种方式，都在任意软件里有效：

    • 鼠标拖选一段文字，松开手，横条就在选中的地方弹出来（这是主用法）。 不同软件"提交选区"的快慢差很多，内部会先等一小会儿选区落地、 复制没成功再自动重试两次，所以快速划选、大文档窗口里也都稳；
    • 键盘选中文字后按 Ctrl+C，横条一样会弹（很多软件里不方便用鼠标的场合靠它）。

    松手后要等多久才弹，由「通用 → 触发 → 出现延迟」决定；调到 100~200 ms 可以避开「手还在拖就已经冒出来」的观感。

    如果它在某些软件里很烦（比如游戏、远程桌面、记笔记时的编辑器）， 到「通用 → 应用范围」把它列进黑名单；反过来只想要它在几个软件里弹， 就切成白名单模式。

    ② 横条：它长什么样、为什么是这个颜色

    横条上是一个个图标格子，从左到右就是你排好的搜索引擎。点格子 = 用当前选中的 文字去那个引擎搜索 / 跳转。

    • 颜色：底色按「界面主题」来 —— 选「跟随系统」就跟着 Windows 的日 / 夜间模式走，也可以锁死亮色或暗色；
    • 样式（三选一）：在「通用 → 横条样式」里切换，页面只显示当前样式的配置项 —— 默认 = 纯色底板；磨砂 = 把横条背后的屏幕糊掉；液态玻璃 = 抓一块背后的桌面 当纹理，做真折射 / 色差 / 边缘亮线，背后在放视频时还能开「实时折射」跟着动。 液态玻璃需要 WebGL2，显卡不支持时自动退回磨砂，不用手动操心；
    • 玻璃预设：选了液态玻璃样式后，顶部有「轻量 / 标准」两档一键参数， 下面任意滑块动过就变成「自定义」—— 预设只是快捷方式，不会和手动调节打架；
    • 位置：默认贴着选中的文字弹（下面放不下会自动翻到上方）； 打开「横条跟随鼠标位置」就一律贴着鼠标。
    • 大小：图标大小、内边距、不透明度、磨砂强度都能调， 「通用 → 预览」里改完立刻能看到真实效果。
    • 把鼠标移到格子边缘、或按住空格拖动，可以挪动横条位置；按 Esc 收起。
    ③ 引擎：默认有哪些、怎么换成自己习惯的

    内置了七百多个常用站点，都在「引擎 → 全部引擎」里，点一下就能加到横条上。 横条上的顺序就是搜索栏的顺序，用「引擎」页拖动排序。

    • 三大类分组：引擎按网页引擎（搜索引擎 / 直达网页）、 软件引擎（软件搜索 / 软件直达）、快捷键引擎分成三大类； 横条的「更多引擎」面板也是这个结构，一层层点进去，七百多个也不会迷路；
    • 软件直达 = 先开本机软件：「常用软件」分类里的条目（微信 / QQ / 钉钉 / 飞书 / 企业微信 / 腾讯会议 / Zoom / Teams / Epic 商城……）点一下会 直接唤起你电脑上装的那个软件，能带页面的协议还会在软件内部打开对应页面 （比如钉钉会在客户端里打开官网）。先后试「软件自己的协议」再试「开始菜单里的 快捷方式」，都没装才退回网页打开 —— 老机器上的体验和以前一模一样；
    • 面板里直接搜：在「更多引擎」面板的搜索框打字，五个子类各一节平铺命中项， 在哪一层打字都能全表搜（按 win+shift+s 还能反查快捷键类引擎）；
    • 添加引擎（三种方式）：在「引擎 → 添加引擎」点「＋ 添加引擎」， 选网页引擎（地址带 %s 是搜索、不带是直达）、 软件引擎（填地址直接唤起本机 / 第三方软件）、 快捷键引擎（点了把组合键发给前台软件）—— 表单默认收起，选了方式才出来；
    • 分隔线：把图标分组用，加几条随你，开头的 / 结尾的 / 连着重复的会自动收掉；
    • 换图标：在横条那一行点右键 → 换图标，从电脑里挑一张 PNG， 图片只存在本机（换电脑要跟着备份走）；
    • 自定义引擎：公司内网搜索、某个小众站点，填一条带 %s 的地址就能加进来，分类选「AI 工具」还会自动带上提问后缀；
    • 快捷键引擎的键位：组合键怎么录、哪些键不能录，见 ⑦ 快捷键一览； AI 类引擎的提问后缀怎么改，见 ④ AI 工具。
    • 快捷键引擎可以「绑定应用」（添加/编辑快捷键引擎时那块浅色区域）： 勾上「先确保这个应用在运行」，再点「选择…」挑一个程序（.exe / 快捷方式）， 之后点这颗图标会先看那个程序开没开 —— 开着就直接把组合键发给它； 没开就先把它拉起来、等窗口出来，再把键发过去。 还能勾「以管理员身份打开」（只影响由我们拉起来的那一次，会弹 UAC； 程序已经在跑时不会去动它的权限）。 不勾这个开关就是老行为：不管程序在不在，直接把键发给当时的前台软件；
    • 搜索地址可改：官方页面哪天改了参数，不用等新版本，自己改一行就行。
    • 「最近使用」一栏：横条的「更多引擎」面板最上面（所有分类之上） 会多出这一栏，按最近顺序排你刚用过的引擎 —— 常用的那几家不用翻分类。 一栏最多摆几个在「引擎 → 更多引擎面板」里选：5 / 10 / 15 / 20。 刚装好、还没用过任何引擎时那一栏不占位（空着不如不显示）； 横条上已经固定住的引擎不会出现在这一栏里 —— 它们本来就在眼皮底下，再抄一遍只会把真正需要"捞回来"的那几家挤掉。 名单里已经不存在的引擎会被跳过（不会留一颗点了没反应的格子）， 但你的使用记录本身不会被删掉 —— 万一那个引擎又被加回来，它还在。
    ④ AI 工具：一选一点，问题就提完整了

    光把一段话丢给 AI，它常常反问「你想让我做什么」。在「AI 工具」里给每个 AI 配一句后缀（例如「这句话什么意思？」），点图标时它会被拼在选中文字后面一起发过去。

    • 没单独配的 AI 用上面的「默认后缀」；
    • 个别 AI 网页不吃 URL 参数？打开「同时把提问复制到剪贴板」， 切过去点输入框 Ctrl+V 就能补上；
    • 选中我在用的这段字 → 点 DeepSeek 图标 → 新标签页里就是一份完整提问。
    ⑤ 文字识别（OCR）：把屏幕上的字抠成可复制的文本

    按 Ctrl+Alt+O（或横条上的 OCR 格子）→ 屏幕变暗、拖框选中一块区域 → 松开即识别。 识别结果窗上面是图、下面是文字；文字里有链接时会出现「打开链接」。 想换引擎去「文字识别」页的引擎列表点一家（那就是默认引擎）。

    框选的是图片而不是想认字？那是另一件事，见 ⑤b 识图搜索。

    • Windows 本地（默认）：用系统自带 OCR，离线、免费、最快，不需要任何账号。 环境检测是手动的 —— 想知道这台机器能不能用，去「文字识别」页点一下 「检测本地 OCR 环境」；不点就不查，也不会主动告诉你结论；
    • 在线引擎一共十多家，在引擎列表里点一家即设为默认：选中的那家会展开 （凭据 / 测试连接 / 挑模型都在展开块里），其余家折成一行名字； 横条按钮 / 快捷键 / 划词兜底都跟着默认引擎走 —— 不存在"加了却没用上"。分两类：
      · 走大模型的（硅基流动、Kimi、智谱、阿里云百炼、火山方舟、OpenAI、 Gemini、OpenRouter、自定义）：兼容 OpenAI 接口，填 Key 之后点 「拉取模型」挑一个模型（会看图的排前面，也能手填）；
      · 专用接口的（百度云、腾讯云、有道、OCR.space、Mistral OCR）： 按提示填 Key / Secret / 接口地址；
    • 测试连接：凭据填完点它，会真发一次请求。连上了、密钥无效、余额不足、 模型名写错 —— 这几种分得很清楚，报错里带上对方的原话，不是只给一个 403；
    • 一键诊断（每一家都有）：实测各环节耗时 / 真发一次请求，把对方的 原话和一句人话建议摆出来；每个环节的按钮点什么由你自己决定， 不会擅自改你的配置；
    • 结果窗固定在默认引擎（默认开）：同时识别多家时，结果窗始终停在默认引擎那一档 —— 它还没回来就显示它的等待文案，回来了原地填上，不会自作主张跳到先出结果的那一家； 想看他家自己点底部的胶囊。关掉开关才是「谁先出字先显示谁」；
    • 同时识别（可多选）：在默认引擎展开的那块里，把还想一起跑的几家勾上，点一次识别它们就同时跑同一张图，结果各占一段、各自标注；底部「显示」段控只看某一家或都看（切档位不重新识别）。没勾的一律不参与，结果框里也不会出现它 —— 包括本地识别。
    ⑤b 识图搜索：框一块屏幕，交给搜索引擎看图

    和 OCR 是「一张图两种读法」：OCR 读出上面的字，识图把它当成图片拿去搜。 点横条上的 🖼（或设了快捷键）→ 屏幕变暗、拖框选中一块区域 → 松开即按配置开浏览器。

    • 十二家引擎，一家一行：在「识图搜索」页，每家单独占一行 —— 行首勾选 = 参与搜索，行尾三颗小按钮（默认 / 换图标 / 问号）都只对这一行生效。 不再有"一个胶囊里塞十几家"的那种选法；
    • 默认引擎：行尾那颗「设为默认」点一下就换成它（换成之后变成 「当前默认」，不会重复触发）。配了默认引擎，框选完直接跳浏览器， 不再问你要用哪家；不配就按勾选名单全部打开；
    • 每家的图标能单独换：行尾那颗「换图标」，从电脑里挑一张 PNG， 只影响这一家（没换过的用默认图标）；
    • 行尾的问号 ❓：点了直接打开这一家官方页面 / 使用方式。 十二家各有各的地址，都在各自那一行；
    • 多选同时搜：勾多家，一次框选后每一家的结果各开一个新标签页 （最多 15 个，多了只开前 15 个）；
    • 三种走法，界面上每家那行小字写的是它：
      · 真上传（Yandex / 百度 / SauceNAO / trace.moe）：软件自己把图 POST 过去， 拿到结果页地址再开浏览器 —— 框选完直接落在结果上，不用再动手。 默认勾选的就是这一档里实测通过的两家（Yandex + SauceNAO）；
      · 打开页面（豆包 / 通义 / Kimi / 智谱 / 元宝 / 文心）： 打开这一家的页面，同时把截图放进剪贴板；这六家还会自动补一次 Ctrl+V（r66 起再补一次 Enter，图发出去它就直接答）；
      · 按图片地址（Yandex / trace.moe 的地址版）：只认你自己填的公网图片链接。 软件刻意不会把你的截图先传到某个第三方图床再拿地址去搜 —— 那等于在你同意「识图」之外，又默默同意「把我的截图交给一个图床」。
    • 动漫截图用 trace.moe：那一行回的不是网页而是一串数据，软件会把它 渲染成一张本地结果页再打开 —— 番名（含中文）、第几集、几分几秒、 相似度、预览视频都在上面。页面在临时目录里，关闭即失效；
    • 哪些家要你「选一下文件」（AI 六家）：浏览器不允许 往文件框里粘贴，光有剪贴板没用。所以这几家会自动给你留一张临时图， 页面里点「选择文件」选它就行（AI 那几家的输入框可以直接把图拖进去）。 这张临时图每轮覆盖、退出即删，硬盘上任何时刻最多只有一张；
    • 真上传也可能失败：百度识图当前对方反爬收紧，上传可能被拒 —— 被拒时软件会自动退回打开它的上传页，你自己点一下「本地上传」选那张临时图即可， 流程不会断；
    • 要不要出现在横条上：「识图搜索」页的「加到划词横条」开关控制那颗 🖼。 关掉之后识图功能还在，只是得从设置页进；
    • 横条上的 🖼 只有开了总开关、又开着「加到划词横条」时才出现， 和 OCR 那颗格子一样跟着配置走。
    • 截图用完就没了：框选出来的图不进硬盘的"长期"存储 —— 它只在内存里、以及剪贴板里过一手。剪贴板那份用完立刻还原 成你原来复制的内容（不会把你的剪贴板换成一张图、也不会留下 "重启还在"的痕迹）。唯一会落盘的是上面说的那张临时图， 它每轮覆盖、退出即删，硬盘上任何时刻最多一张。 OCR 那条路压根不碰剪贴板，也不留文件。
    • 选中一段本地文件路径时横条上多出来的那颗是 📁 不是 🖼 —— 那是另一件事，见 ⑤c 文件路径。
    ⑤c 文件路径：选中一段路径，直接定位到它

    聊天里、报错里、文档里出现一段本地路径时，选中它 —— 横条上会自动多出一个 📁 图标，点一下就用系统资源管理器打开那个位置。

    • 认得出来的是这些形态：带盘符的（C:\Users\me\a.txt）、 网络共享（\\server\share）、带斜杠或反斜杠的相对 / 绝对路径 （D:/资料/合同）、含环境变量的（%APPDATA%\QuickSearch）、 以及从浏览器地址栏复制出来的文件地址（file:///C:/Users/me/a.txt）；
    • 选多了也不怕：划词时把首尾的引号、句号、逗号一起选进来 （"C:\a\b.docx"， 这种）照样能开 —— 这些标点会被自动剥掉。 Windows 文件名本来就不许以点或空格结尾，所以剥掉它们只会更准；
    • 是文件就定位到它：在资源管理器里选中那个文件，而不是只打开它所在的文件夹；
    • 打不开会有反馈：路径不存在、或者盘没插上，横条上会直接说清楚，不会静默无反应；
    • 认不出来的不会硬猜：裸的 bin\tool.exe（没有盘符 / UNC / 前缀） 不弹图标 —— 误判的代价是横条上凭空多一颗、点下去弹个报错，比"没认出来"烦人得多；
    • 网址（https:// 开头、或以 // 开头）不算路径， 不会和「打开链接」打架。
    • 反过来，选中网址时横条上那颗是打开浏览器（横条自己就带）； 选中图片想搜图那是另一件事，见 ⑤b 识图搜索。
    ⑥ 收藏夹：常用文字 / 图片，点一下就复制

    「收藏夹」页最多两级目录。添加一级目录 → 给它起个名字 → 把常用的一句话、一个地址、一张图片丢进去。

    • 放进横条：给目录配个图标后，横条上点它就列出里面的内容，点一条复制一条；
    • 点击的去向：如果鼠标底下那个软件正好有输入框，文字会直接打进那个输入框； 没有可用输入框时，才退回「复制到剪贴板」；
    • 拖动：目录按住左边的 ⋮⋮ 把手拖（排序 / 变成二级 / 升回一级）， 内容行长按半秒拖动（本目录排序 / 移到别的目录）；
    • 快捷键：在这一页给「唤起收藏夹」配一个组合键，点「清除」就是不设快捷键；
    • 目录名平时是锁住的，想改名点「重命名」；「全部展开 / 全部折叠」只管目录层级， 不会把里面的条目摊成编辑状态。
    ⑦ 快捷键一览（都可以改，也都可以取消）
    • Ctrl+C —— 弹出横条（可在「通用 → 触发」关掉）。选词复制时顺手弹出来，是它最好用的入口；
    • Ctrl+Alt+O —— 开始框选文字识别（可在「文字识别」页关掉整个功能）；
    • 收藏夹唤起键 —— 自己录一个，「清除」= 不要快捷键；
    • Esc —— 收起横条 / 退出快捷键录入。

    录快捷键时点一下按钮，再按下想要的组合（要带 Ctrl / Alt / Shift 之一）。 录到一半改主意就按 Esc，或点别的地方。

    识图目前没有快捷键，从横条上的 🖼 进（见 ⑤b）； 屏幕上出现本地文件路径时选中它，横条上会自动多一颗 📁， 点它就能定位到那段路径（见 ⑤c）。

    ⑧ 备份与恢复：先落本地，再上云端

    一次「立即备份」= 先在本地备份目录里落一份，再把同一份 上传到云端 —— 本地那个文件和云端那个文件同名同内容 （config(详细时间).QuickSearch），所以云端会一份份累积， 想恢复哪一次就挑哪一次。文件名不用你操心：本地叫什么，云端就叫什么。

    • WebDAV：坚果云 / Nextcloud / 群晖都行。地址只填到根地址， 后面的目录软件会自己补、文件夹也会自动建；坚果云请用「应用密码」而不是登录密码；
    • 加密：设了备份密码后，所有备份（云端上传、本机导出）都是 AES-256-GCM + Argon2id 加密的，文件里看不到任何原文。密码丢了就解不开；
    • 自动：可以打开「启动时同步」（比较云端最新一份和本机，谁新用谁） 和「退出时同步」（退出前推一份上去）。这两个都只在配置真的改过时才传 —— 不然每开一次软件就多一个云端文件，配置一个字没动也一样；
    • 恢复：点「从云端恢复」会列出云端所有备份，挑一份即可； 恢复前会自动在本机留一份快照，恢复错了还能退回去；
    • 清理：「仅保留最近 10 份」会把本地和云端一起清， 只留最新 10 份；想自己挑着删，点云端列表右上角的「管理」， 所有云端备份会变成可勾选状态，勾完点「删除选中」；
    • 备份内容：所有设置与外观、横条上的引擎与排序、自定义图标、 收藏夹整棵树、OCR 的 Key、WebDAV 的账号密码、快捷键 —— 换台电脑恢复就等于恢复了一切。
    ⑧b 明文导入 / 导出：只把自己想要的那几项给出去

    和 ⑧ 备份是两件不同的事，别混用：

    • 备份（.QuickSearch）= 整份配置、可加密、恢复时 整份覆盖 —— 换电脑、重装系统用它；
    • 明文导出（.qsconf）= 挑几项、不加密、 导入时只覆盖那几项、别的不动 —— 给同事分享一份设置用它。

    在「数据」页点「导出」，先勾你想要的那几项：

    • 默认只勾非隐私项：引擎配置、应用设置、图标、识图搜索这四项默认是勾上的； API Key、收藏夹、备份设置这三项默认不勾 —— 分享前先看一眼勾了哪些， 别把 Key 发给别人；
    • 勾了几项，按钮上就写着「导出 3 项…」；一项都不勾时点它不弹对话框 （没什么可导出的，就不打扰你）；
    • 导出的文件是纯文本 JSON，用记事本就能打开看、能改， 没有加密 —— 所以它可以直接发给别人导入，也正因如此别用它传密码；
    • 导入是合并式的：只把文件里带的那些项灌回去，你现在的收藏夹、快捷键 一个字都不会被动。反过来也意味着：用它「恢复现场」不会删掉你现在多出来的东西 —— 要完整覆盖请走 ⑧ 备份那条路；
    • 明文导入只吃明文导出：拿加密备份（或整份备份文件）去导会直接被拒， 并提示你去「备份」页 —— 两条路各管一件事，不会把「导入」悄悄变成「全量覆盖」。
    ⑨ 托盘图标与退出

    软件常驻在右下角托盘里。右键托盘图标可以：打开设置、立即备份、开始识别、退出。

    想彻底退出就点托盘菜单里的「退出」—— 关掉设置窗口不会退出程序， 它还要留在后台等你下次选中文字。

    ⑩ 我的数据都放在哪
    • 配置：%APPDATA%\QuickSearch\config.json（备份目录可以改到别处）；
    • 换过的图标：%APPDATA%\QuickSearch\icons\；
    • 备份：滚动备份 config.auto(时间).QuickSearch、恢复前快照 config.before-webdav(时间).QuickSearch， 以及你点「立即备份」落下的那一份 config(时间).QuickSearch（和云端同名）。
    • 你导出的明文配置（.qsconf）存在你自己选的地方， 软件不会自动往数据目录里塞 —— 怎么挑着导、怎么分享， 见 ⑧b 明文导入 / 导出。那份文件你打算发给谁， 责任就在谁手上。
    • 识图的截屏、OCR 的截屏都是临时的：用完即丢， 不会留在硬盘上（识图那三家"填图片地址"的引擎除外 —— 那是你自己填的公网链接，软件只是打开它）。

    分享给别人是安全的：软件本体里不含任何账号信息 —— OCR 的 Key、 WebDAV 的账号密码都只写在本机那份 config.json 里， 跟着配置走、不跟着软件走。对方拿到的是一份「干净」的程序。
