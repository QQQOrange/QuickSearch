# Quick Search v1.3.8 发布说明

> 发布日期：2026-10-22
> 上个版本：v1.3.7
> 这一版修一个你报的 bug（选中网址不弹按钮）+ 加一个你要求的新功能（选中文件直接打开）。

---

## ① 选中网址却不弹「打开网址」按钮

你的原话：

> 「我选中了一个网址但横条里并不能够弹出直达网址的按钮，但是如果我把这段网址
>   复制下来了，因此而弹出的横条里面却能有直达网址的按钮，这个要修。」

### 根因：两条路拿到的**文字**不一样

按钮显隐看的是「这段文字里有没有链接」。而两条触发路径拿到的文字来源不同：

| 路径 | 文字来自 | 干净程度 |
|---|---|---|
| **Ctrl+C 复制** | 剪贴板原文 | 干净（你选中的就是它） |
| **鼠标划词** | `capture_without_clipboard` | 浏览器里 UIA 被整体跳过 → 落到 **OCR 兜底** |

OCR 出来的东西带它自己的噪声，最常见三种：

```text
https:// www.baidu.com        ← 把协议和主机名断开
https://a.com␣              ← 行尾多一个空格
https://​a.com               ← 夹带零宽字符（网页复制常见）
```

原来的判据是「整串是不是一条网址」，这三种都判失败 → `isUrl = false` → 按钮不出现。
而复制路径拿到的是干净原文，轻松命中 —— 所以同一个动作两条路结论相反。

### 修了两处

**① 判据对 OCR 噪声放宽**（`engines::text_to_url` / `extract_links`）

- 协议名可以在**任意位置**（`请访问 https://a.com` 也算）；
- 空白和零宽字符会被接回去（`https:// www.baidu.com` → `https://www.baidu.com`）；
- `extract_links` 也补了"接续"：从断开处往后跳过空白再拼一次。

**② 按钮点下去时把文字一起发给后端**

以前是 `invoke('open_link')`（不带参数），后端读共享状态里的 `sel_url` ——
而划词路径上 `sel_url` 正是那个判失败的 `None`，于是**按钮亮着、点下去什么都没发生**。
现在前端把这段文字传过去，后端拿它重新过一遍判据，失败也有兜底（直接开原文）。

### 假阳性防线一条都没退

放宽的同时加了更严的主机名校验（`host_of`：主机名必须含点、或是 IP）：

```text
拒：index.html   package.json   test.js   C:\www\index.html
拒：https://   https:// 说明   https://​（只有零宽字符）   https://www.（不完整）
认：https://zh.wikipedia.org/wiki/中文   http://192.168.1.5:8080/x
```

## ② 新增：选中文件路径 → 📄 用默认程序打开

你的原话：

> 「还要再增加一个直达文件的功能，就是说我选中了一个文件路径，那这个时候横条上
>   就会弹出一个按钮，点击这个按钮就会自动调用系统默认的相应文件的软件来打开这个文件。」

### 现在横条上有两颗路径按钮

| 按钮 | 行为 | 什么时候出现 |
|---|---|---|
| 📁 | 在**文件管理器**里定位/打开（资源管理器） | 选中路径（文件或目录） |
| 📄 | 用**系统默认程序**打开（.txt → 记事本、.mp4 → 播放器） | 选中路径且**是文件** |

📄 走的是 `ShellExecuteW("open")` —— 就是 Windows 的文件关联，和你在资源管理器里
**双击这个文件完全一致**（没有关联的程序会弹出系统"你要用什么打开"对话框，那也是双击的行为）。

**目录只给 📁**：目录没有"默认程序"这个概念，双击目录本来就是资源管理器打开。

### 「是文件还是目录」问谁

问后端（新增只读命令 `path_kind`）。因为 `resolve` 要展开 `%VAR%`、拼工作目录、
还原 `file://` 编码 —— 这些逻辑全在后端，前端重复一遍必然分叉。
所以 📁 立即可见（不依赖 IPC），📄 等一次 IPC（几毫秒，无感）。

## ③ 你问的「直接打开文件夹是不是也是这样」

审了一遍，**文件夹那条路没有 URL 那种分叉**：

- 判据（`paths::looks_like_path`）是同一套，划词和复制两条路拿到的文字只要像路径就都弹；
- 前后端各留一份判据是刻意的（前端要不调 IPC 就弹图标，后端要不轻信前端），口径逐字同源。

但它的能力以前只有"在资源管理器里定位"，所以这一版给**文件**补上了"直接打开"。
