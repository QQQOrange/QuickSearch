# Quick Search v1.5.4

**一个新功能：横条弹出位置可以选了（文字上方 / 下方）。另附：「点横条外面就收起」的核查结论。**

---

## 一、新增：横条可以选「弹在文字上方还是下方」

你的原话：

> 还要可以选择横条是在选中文字的上方还是下方，在设置 外观 栏目中可以调整

**设置页 → 外观 → 横条外观 → 弹出位置**，两档：

| 档位 | 行为 |
|---|---|
| **文字上方**（默认） | 胶囊底边贴在选中文字上沿之上 —— 和以前完全一样，不盖住你刚选中的字 |
| **文字下方** | 胶囊顶边贴在文字下沿之下 |

三条行为规则：

1. **这只是首选方向**：选的那一侧放不下时，照样自动翻到另一侧
   （例：选了「下方」，但文字就在屏幕最底下 → 翻到上方）。不会出现
   "选了下却飞出屏幕"。翻侧逻辑提成了纯函数 `pick_bar_side`，五种情形
   （上下都放得下 / 上放不下 / 下放不下 / 两侧都放不下 × 两个首选方向）
   都有单元测试钉住。
2. **「跟随鼠标位置」打开时本项无效**（Ctrl+C 触发的那条路也一样）——
   那两条路没有"文字在哪"的信息，一律贴鼠标。此时控件自动置灰，
   看得见但点不了，不会以为"选了没生效"。
3. **不用重启**：设置里改完，下一次弹横条（哪怕只是面板开合引起的重排）
   立刻按新方向摆。

方向决策会写进日志（`place: side=above|below|…-clamped`），探针可以断言
"用户选了下就真的在下面"。

## 二、「点横条外面就收起」—— 核查结论：一直都有

你这次也提了这条：

> 给 qbar 弹窗加一个逻辑，弹窗出来之后，点击非弹窗之外的任何地方，弹窗会消失

查下来 **v1.3.0 起就已经实现**，不需要重复开发。链路（全局低级鼠标钩子
→ 判落点 → 收起）：

| 情形 | 行为 |
|---|---|
| 左键点到横条**外面**（别的窗口 / 桌面 / 任务栏 / 另一块屏，都算） | 立刻收起 |
| 右键点到横条外面 | 立刻收起 |
| 点到横条自己身上（含展开的面板、右键菜单） | 不收起，照常操作 |
| **收藏夹面板被钉住时**点外面 | 故意不收起（"钉住"的语义就是别被随便点掉；Esc / 收起飞按钮照旧能收） |

从本机运行日志里抽查了真实序列：`show_bar → 窗口可见(8ms) → 点外面 →
dismiss_bar: 已收起`，链路是通的（该日志文件里此类记录累计 282 次）。
唯一没覆盖的是中键 / 鼠标侧键（你说的"点击"默认指左键，没为它们加收起——
中键在浏览器里是"新标签页打开"，那条路把横条收掉反而可能打扰）。

> 要是你遇到过"点了外面却没收起"，告诉我是哪种情形（比如点在横条半透明的
> 阴影上？），我复现后修。
