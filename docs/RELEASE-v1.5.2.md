# Quick Search v1.5.2

**双击托盘图标 = 打开设置。**

---

## 改了什么

你的要求：

> 添加一个逻辑，双击托盘上的图标，打开设置。

现在进设置只有两条明确的路：

| 手势 | 结果 |
|---|---|
| **双击**托盘图标 | 打开设置窗口 |
| **右键**托盘图标 | 菜单（设置 / 立即备份 / 开始识别 / 退出） |

**单击不再打开设置。** 托盘图标紧挨着时钟，误点一下就弹出一个设置窗太容易了 ——
这一版前半段修的正是「误触发」（乱弹、乱开）。单击现在什么都不做。

## 顺带填的一个底层坑

Tauri 用的托盘库（tray-icon 0.25）给托盘消息窗注册的窗口类**没带 `CS_DBLCLKS`**
（`WNDCLASSW` 是 `..zeroed()` 出来的，`style = 0`）。而 `WM_LBUTTONDBLCLK` 是系统
按**窗口类样式**决定发不发的消息 —— 所以「只写一条 `TrayIconEvent::DoubleClick`
分支」的话，在 Windows 上很可能一次都不触发：双击毫无反应，日志里也什么都没有。

所以现在是两条路一起走：

1. 原生 `DoubleClick` 事件来了就开（将来托盘库补上这个样式也照样对）；
2. 没来就自己判：**两次左键抬起落在系统双击时限内**。时限取
   `GetDoubleClickTime()`（默认 500ms，你在 Windows 鼠标设置里调到 200~900ms
   也跟着走），不是写死的常数。

另外加了一道 500ms 去重：同一个双击手势可能被两条路各触发一次，不会连开两次窗。
