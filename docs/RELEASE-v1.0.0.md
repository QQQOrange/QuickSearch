# Quick Search v1.0.0

首个正式版本。Windows 10/11 划词搜索工具，**单 exe、免安装、无需运行库**。

---

## 这是什么

在任意软件里选中文字，屏幕上方就弹出一条搜索横条：点一颗图标，选中的词就交给那个
网站 / 软件 / 快捷键去处理。另外还带截图识图、屏幕文字识别、收藏夹、图标编辑器和
加密备份。

**替代的操作路径**：以前要「复制 → Alt+Tab → 开浏览器 → Ctrl+L → 粘贴 → 回车」六步，
现在一次点击。

---

## 主要功能

### 划词横条
- 选中文字松手即弹（也可选 Ctrl+双击 / Ctrl+C 触发）
- 支持「贴光标」与「贴选区」两种定位，不出工作区
- 引擎可拖拽排序，可插入分隔线，可换图标

### 777 个内置引擎
- 27 个大类（网页 / AI / 知识 / 开发 / 翻译 / 地图 / 图片 / 音乐 / 视频 / 购物 /
  应用 / 游戏 / 网盘 / 学术 / 社交 / 新闻 / 词典 / 财经 / 学习 / 阅读 / 汽车 /
  生活 / 工具 / 邮箱 / 软件搜索 / 常用软件 / 快捷键）
- **85% 带经典别名**：搜「B站」→ 哔哩哔哩，搜「度娘」→ 百度，搜「gayhub」→ GitHub
- 四级目录下钻 + A–Z 首字母聚合索引
- 自定义引擎三种类型：网页搜索 / 直接打开 / 快捷键

### 截图识图（12 家）
- 真上传：百度、Yandex、SauceNAO、trace.moe
- AI 看图 6 家：豆包、通义、Kimi、智谱、元宝、文心
- **AI 优先**：先开 AI 页面、按完快捷键，再开其余引擎
- **按键延迟可配**：开页→Ctrl+V、Ctrl+V→Enter 两段独立设置
- 截图不落盘，用完还原剪贴板

### 文字识别（15 家）
- 本地离线（Windows 内置 OCR）+ 百度 / 腾讯 / 有道 / OCRSpace / Mistral /
  智谱 / 通义 / 方舟 / 硅基流动 / Kimi / OpenAI / Gemini / OpenRouter / 自定义
- **多引擎同时识别**：结果窗并排多个文本框，各引擎结果分开显示
- 模型列表默认只留视觉模型（纯文本模型吃不了图）
- 未配凭据时自动回退本地 OCR，不会「点了没反应」

### 图标编辑器（r79 重做）
- **自动抠图**：**颜色解混**算法，不是颜色泛洪
  - 逐像素估背景色（二次曲面最小二乘）+ 逐像素估前景色（腐蚀后前景的局部均值）
  - 按合成方程 `I = αF + (1-α)B` 反解 `α = ((I-B)·(F-B))/|F-B|²`（闭式解、不迭代）
  - 浅色主体落在浅底上**正确保留**（旧算法会吃掉主体）
  - 主体内部的浅色细节（如描边）**不被删**
  - 边缘混色像素的 RGB 置为纯前景色 → **不留白边**
  - 512×512 复杂图标 17~39ms
- **手动补描**：作为**硬约束前景**（描过区域无条件保留）；
  主体与背景同色、方程欠定时才需要
- **无背景时不毁图**：主体顶满四边/整体同色 → 原图不动 + 明确提示
- **光学尺寸归一**：带透明留白的图标自动放大

> 关于算法选择：试过照 pymatting 实现完整的 Closed-Form Matting
> （matting Laplacian + 共轭梯度），实测对平涂图标不适用（未知率 11~17%、
> 耗时 132~394ms，且迭代 12→300 轮结果几乎不变）—— CF 的"局部颜色线"假设
> 是为自然图像设计的。另两个参考项目（image-matting / removebg）用的是
> 神经网络 RMBG-1.4（26.78MB ONNX），效果好但会把单 exe 从 11.7MB 撑到 40MB 左右，
> 故未采用。

### 其他
- **收藏夹**：两级目录，文字 / 图片 / 富文本，可拖拽
- **图标编辑器**：一键消除背景 + **手动描边保护**（解决浅色主体被误删）+ 光学尺寸归一
- **加密备份**：AES-256-GCM + Argon2id，支持 WebDAV 云端同步
- **主题**：亮 / 暗 / 跟随系统，横条支持液态玻璃（WebGL2 真折射）

## 安装

1. 下载 `QuickSearch.exe`
2. 放到任意目录，双击运行（无需安装）
3. 首次运行会请求管理员权限 —— **这是必需的**：只有管理员进程才能把 Ctrl+C
   送进同样是管理员的程序（任务管理器、各类编辑器）。可在设置里关闭自动提权。

**系统要求**：Windows 10/11 x64，WebView2 Runtime（Win11 内置；Win10 若缺失会提示）。

## 已知限制

- 部分游戏全屏独占时，全局钩子可能失效
- UIA 读不到选区的程序会退回「模拟 Ctrl+C + 读剪贴板」；若该程序禁用复制则无文本
- 识图「按图片地址搜」那两家需要自己填一张公网图片地址（软件不代传截图）
- 仅支持 Windows；macOS / Linux 未适配
