## ② 搜不到引擎：四个坑叠在一起

| # | 坑 | 表现 |
|---|---|---|
| ① | 敲**第一个字符**时面板命中"内容没变就不重画"的缓存（r92 的防闪优化），那一下**既没筛选、也没填充格子** | 「打进去没反应」，第二下才出结果 |
| ② | 关面板只复位了「大类」筛选，**中类 / 小类**那两个筛子留在内存；而它们的按钮是"选了大类才出现"的 → 筛子变成一个**既看不见、也点不掉**的隐形过滤 | 搜索只在一半引擎里进行：搜「哔哩哔哩」只出「（首页）」 |
| ③ | 搜索态没收起「最近使用」那一栏 | 回车可能选中藏在已隐藏区域里的格子 |
| ④ | `ENGINE_BY_NAME` 先注册横条固定位（`toolbar`），而 toolbar 条目**不带别名** → 同名引擎在引擎库那份里的别名（B站 / 小破站 / bilibili）被遮掉 | 按别名搜一律搜不到 |

四处都修了：进搜索态就清掉三层筛子（只在"刚进入"那一下清，搜索途中你主动点的大类胶囊不动）、第一下输入立刻生效、搜索时用 `hidden` 收起「最近使用」（不重画、不闪）、别名改成**全表合并**的索引。

实测（无头 jsdom 跑真实 `ui/bar.js`）：

| 场景 | v1.4.1 | v1.4.2 |
|---|---|---|
| 打开面板直接搜「哔哩哔哩」 | 只有「哔哩哔哩（首页）」 | 哔哩哔哩 / 哔哩哔哩（首页）/ 哔哩哔哩漫画（首页） |
| 选过大类+中类 → 关面板 → 重开 → 搜 | **一条都搜不到** | 同上三条 |
| 逐字输入「哔」「哩」「哔」「哩」 | 只出 1 条 | 3 条 |
| 搜别名「B站 / 小破站 / bilibili」 | 只有「（首页）」 | 哔哩哔哩 + （首页） |

## ③ 快捷键引擎"被删了"：其实是恢复备份把数据打坏了

不是它们本来就空，也不是你记错。本地备份时间线（全部解密比对）：

| 时间 | 微信截图 / 章鱼速贴快捷输入 |
|---|---|
| 10-20 — 10-22 **12:18**（每一份） | `kind:hotkey`，`alt+a` / `alt+v`，绑定了微信 和 Octoclip |
| **13:56 之后** | 全变成 `kind:search`、`url:""`、`hotkey:""` |

13:56 的日志：「`webdav: 启动同步：云端「config(2026-10-22 12-25-37).QuickSearch」较新，已恢复到本机`」。
云端那份备份里**没有"种类 / 按键序列 / 绑定应用"这几个字段**，serde 按默认值一填，快捷键引擎就被打回"搜索类 + 没地址 + 没按键"的空壳 —— 横条画不出来、引擎库里也查不到，看起来就是"引擎被删了"。

三件事一起做：

1. **恢复你的数据**：按 12:18 的本地备份把两条定义原样写回（`微信截图` = `Alt+A` 绑微信、`章鱼速贴快捷输入` = `Alt+V` 绑 Octoclip 管理员启动），横条顺序也按当时还原（百度 / 必应 / Google / ｜ / 章鱼速贴快捷输入 / @ocr / 微信截图）。
2. **堵住根因**：恢复备份时，如果备份里某条定义**缺字段/不可用**、而本机同名那条是好的 → **保留本机那份**（和"空密码不覆盖本机密码"同一条口径）。
3. **不再隐藏任何引擎**：万一以后又出现"定义不完整"的自定义引擎，横条上会**照常画出来**（半透明 + 右上角红色「!」），点一下提示「去 设置 → 自定义引擎 补上」；设置页那一行也会标红。任何情况下都**不删定义、不从横条摘掉**。

## ④ 顺手做的两件

- **小类目录平铺**：横条面板第三级（视频 / 音乐 / 购物…）从"一个胶囊 + 下拉菜单"改成**一整行紧凑胶囊**（24 颗约 3 行），点谁只剩谁；设置页引擎库的小类胶囊统一成"点一下 = 只看这一类，再点一次恢复全部"。
- **面板出场动画**：本体淡入 150ms，头 / 身 / 尾各自从上方 7px 落位（190ms 强缓出），尾部晚 10ms。⚠ 位移只放在子元素上 —— 面板本体一旦带 transform，`pushLayout` 量窗口尺寸时会量到动画中间态，面板边缘会被硬切掉一块。设置里关掉动画 / 系统「减少动态效果」都会老实不播。
