# v1.5.14 —— 多语言 / 自动更新窗 / 启动密码

> **这一版把 v1.5.13 和 v1.5.14 一起发了。** v1.5.13 只推过代码、没发 Release，
> 所以现在还在 v1.5.12 的机器升上来会一次拿到下面**全部**内容。

三件独立的活：**界面多语言（简体中文 / English）**、**启动时检查更新并给出可
取消的下载窗**、**可选的启动密码**（与备份密码完全独立）。之后 v1.5.14 又修了
启动密码的两个真问题，并加了一条"关密码要先验密码"。

## 1 多语言：中文原文当键，DOM 层替换

不做 `data-i18n="key"` 那套 —— 那得把整个设置页（1500 行 HTML + 9000 行 JS 里
几百句 `textContent = '…'`）全改成查表，改动面比翻译本身大得多，还会把拼字符串
的地方全打碎。

实际做法是**中文原文就是键**：运行时按文本节点 / 整句 / 属性查表，命中了就换，
同时把原值记进 `RECORDS`。切回中文按记录**逐字还原**，不是"再翻一遍"。

| 层 | 手段 | 覆盖 |
|---|---|---|
| 单个文本节点 | 字典精确命中 | 大多数按钮、标签 |
| 一句带内联标签的话 | 整句命中，译文可带 `<b>` | `.hint` / `small` / `li` |
| 极长静态文（帮助页） | `data-i18n-block` 整块换 innerHTML | 帮助卡片 |
| JS 拼出来的提示 | `p:` 前缀 / `s:` 后缀碎片 | `已添加「X」并固定到横条` |
| 带数字的句子 | `RULES` 正则（只整串匹配） | `共 5 项` → `5 items` |
| 后来才出现的文案 | `MutationObserver` 兜底 | toast、列表刷新 |

字典是**生成**的，`ui/i18n.en.js` 别手改：

```bash
node tools/gen-i18n.js      # 合并 _i18n_parts/*.json + *.html → ui/i18n.en.js
node tools/i18n-audit.js    # 补漏：切到英文后还剩哪些中文，带位置
```

当前规模：`entries=994  blocks=2  frag=87  rules=55`。设置 → 系统 → 语言，
选完立即生效并写进配置（`uiLang`），重启后仍是英文。

### 一条诚实的边界：引擎名不翻

`百度`、`豆瓣读书`、`哔哩哔哩`… 600+ 条内置引擎名，加上你自己加的引擎名，
一律按**数据**处理、不翻译。理由有两条：翻一半比不翻更难看；翻了就和你当初
输入的检索词对不上。所以索引页的 `百度　（左键搜索 / 右键换图标）` 只翻后半句。

要连名字一起翻，得额外做一张 600 行的名字表 —— 那是另一个决定。

## 2 自动更新：检查照旧，多了下载窗和取消

启动检查还是只打 `api.github.com`（本机对 `github.com:443` 时通时不通，所以下载
有备源回退）。查到新版，除了原来那条横幅，现在还会**弹一个独立窗口**：

- `skip_taskbar(false)` —— 任务栏里能看到，切走了也能找回来；
- 实时进度：已下载 / 总量 / 速度，状态机 `prompt → downloading → done / error / cancelled`；
- **取消按钮真能中断**：`AtomicBool` 门禁，读循环每读一块检查一次，命中就断开
  连接走 `DlFail::Cancelled` —— 不重试、不留半截文件。

## 3 启动密码：独立于备份密码

- 只存 **Argon2id PHC 哈希**（`m=19456,t=2,p=1`），配置里没有明文，也不进备份信封；
- 开着时启动即弹无边框锁屏窗，**托盘菜单、全局快捷键、粘贴取词全被门禁挡住**
  —— 不是只挡界面；
- 关掉即清哈希，默认没有密码，行为和以前完全一样；
- 与「备份密码」是两套东西：那个是 AES-256-GCM 用来加密备份文件的，两者
  互不影响，改一个不会动另一个。

## 4 v1.5.14 修的三个问题（都在启动密码上）

**① 首次设密码只有一个输入框** —— 启动密码没有找回入口（忘了只能手改
`config.json` 删掉那行哈希），打错一个字母就把自己锁在门外。现在设密码要输
两遍，不一致直接红字提示 + 清空第二个框 + **一个字节都不写**。

**② 解锁成功后锁屏窗不消失** —— 根因是 `verify_startup_password` 用 `close()`
关窗，而 `on_window_event` 为了挡 Alt+F4，对锁屏窗的 `CloseRequested` 一律
`prevent_close()` —— **程序自己发的关闭请求也被自己拦掉了**。改成 `destroy()`
（不走关闭请求），并让"已解锁"之后的关闭请求放行。解锁后横条随即亮出来。

**③ 关闭密码必须先输一次当前密码** —— 前后端各一道：新命令
`startup_password_disable(password)`，验过才清哈希；`apply_one_setting` 对
`startupPassword` 的空值一律报错（否则一句 `set_setting` 就能把保护卸掉，
"再输一次"就成了摆设）。开关一拨不会直接卸，而是落到「关闭启动密码」验证行，
输错提示「密码不对，启动密码没有被关闭」，也能取消 —— 取消后保护一点没动。

顺带：锁屏窗左下角多了**「退出程序」**。不想输密码、或者只是点错了，可以从这里
干净退出，不用去任务管理器杀进程。这条退出**不跑**「退出时同步」—— 锁着的
时候没必要把配置推到云端。

## 装机

覆盖 `QuickSearch.exe` 即可，配置、收藏夹、图标都不动。

> 配置结构是**新增字段**（`uiLang` 默认 `zh`、`startupPasswordHash` 默认空），
> 老配置读进来会被 `sanitize()` 补齐 —— 从任何旧版本直升都不需要迁移，
> 升上来默认还是**简体中文**、**没有启动密码**，和升级前完全一样。
