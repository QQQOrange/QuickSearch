# Quick Search v1.5.20

> 从 v1.5.18 及更早版本直升的用户：v1.5.19 换掉了翻译 / 识图搜索的默认图标（并全部内嵌），
> 本版接着修了这两个图标的明暗状态，再往下是主题系统的重构。以下一并说明。

## 主要改动

### 1. 设置页「翻译」「识图搜索」图标的明暗修复
上一版把这两个 tab 的图标换成品牌图后，给它们单独写了"不减灰"，结果**任何状态都显示彩色**。
现在恢复统一规则：未选中是灰色（和旁边的 🎨 ✂️ 一致），选中后恢复彩色。

### 2. 主题系统重构：所有窗口终于共用一套皮肤
- 以前设置页和横条用应用内主题，但**识别结果 / 翻译 / 图标编辑器三个窗口只跟系统深浅**。
  用户把主题设成「强制亮色」而系统是深色时，这三个窗口仍然是深色。
- 现在设计令牌（颜色、圆角、阴影）集中到一份 `theme.css`，四个窗口共用；
  统一由 `data-theme`（system / light / dark）驱动，强制亮色能正确盖掉系统深色。
- 顺带修掉已经发生的漂移：`--hover` 两个值、`--danger` 两种色，现在只有一份来源。

### 3. 百度 OCR 精度档：确认切换真实有效
新增回归测试，证明「标准（免费）/ 高精度（付费）」确实走不同接口、拿到不同结果：
- 标准版 → `general_basic`（每日 500 次免费）
- 高精度 → `accurate_basic`（按量付费）
高精度失败时**不自动降级**，原样报错，由你自己决定是否切回标准版。

### 4. UI 细节统一
- 开关圆钮、滑块拇指、索引浮钮的阴影改为随主题变（深色下不再是死黑）。
- 卡片圆角、tab 与索引浮钮的过渡曲线统一到令牌。

## 安装

便携版，无需安装。下载 `QuickSearch.exe` 覆盖原位置即可（旧配置不受影响）。

- `cargo test --release` 全量里 `paths::tests::open_file_用默认程序打开真实文件` 在本机会稳定失败

  与本次改动无关。
