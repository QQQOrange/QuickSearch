**修一个「上一版看着做完、实际没生效」的 bug：横条弹出位置选「文字上方」也弹在下面。**

## 你报的现象

> 并没有真正的实现，因为我不管是调文字上方还是文字下方，最后它出现的都是在文字下方

## 根因（不是判断逻辑错，是它前面的"前提"从来没成立）

v1.5.4 加的 `pick_bar_side` 本身是对的，单测也全绿。问题是它<b>拿不到</b>"文字在哪一行"：

- 程序问系统要光标矩形，走的是 `GetGUIThreadInfo`（`src/win.rs:561`）。
- 这个接口**只有原生文本控件**（记事本、编辑框、Win32 输入框）才会回报光标。
- **浏览器 / Electron 里的光标是网页自己画的**，系统这一层永远是空矩形 → 返回 `None`。

拿不到光标，`layout_bar` 就落到兜底分支「贴鼠标」。而鼠标停在选区的**右下角**，
所以看起来永远在文字下方 —— 选上方还是下方完全没差别。

你本机的运行日志把这个过程记得很清楚，每一行都是：

```text
show_bar: atMouse=false cfgMouse=false caret=None anchor=(1935,1051)
place: side=mouse caret=None gap=12 barPh=66 ...
```

`caret=None` + `side=mouse`，一次都没进过上下侧的判断。

## 修法

**真光标拿不到时，用这次划选的轨迹当文字范围。**

划词这条路上，「按下点」和「抬起点」本来就是现成的几何信息（钩子已经拿到了，
一路传进 `start_capture`）。新增 `selection_box_from_drag`：

- 纵向取两点的跨度（多行选区自动是"第一行到最下行"）；
- 上下各向外让出半个行高（`12 CSS px × DPI 缩放`，夹在 8~36 px）——
  鼠标多半落在字行中间，不让就会把字盖住；
- 横向锚点用抬起点（= 选区末端，和真光标那条路 `caret left` 的语义一致）。

优先级是**拖选轨迹 > 真光标 > 鼠标**：拖选轨迹是"这次选区"的真实范围（多行选区
时真光标停在最后一行，按它判「上方」会盖住上面几行）；没有轨迹（Ctrl+C、键盘选词）
才退回真光标；两者都没有才贴鼠标。

日志多一个字段，能直接看出这次走的哪条路：

```text
show_bar: atMouse=false cfgMouse=false caret=Some((1552,948,1552,996)) src=drag anchor=(1552,996)
place: side=above ... inner=(1552,844) win=(1456,824)
```

## 这次是**真跑过**的，不是只看单测

新增 `tools/r155-barpos-probe.js`：起一个独立实例（不碰你正在用的那个），
给一条确定的拖选矩形，调真的 `show_bar`，再读真日志里的 `place:` 与窗口矩形。
本机实测输出：

```text
拖选矩形（按下→抬起）= [1152,972,1552,972]
[above] src=drag caret=[1552,948,1552,996] side=above inner=[1552,844]  win=824
[below] src=drag caret=[1552,948,1552,996] side=below inner=[1552,1008] win=988
PASS  两次都真的弹出了（after-show visible=true）
PASS  传了拖选矩形就一定按 drag 算（真光标不再顶掉它）
PASS  上方：真的摆在文字（拖选）上方
PASS  下方：真的摆在文字（拖选）下方
PASS  两个选项算出的 y 不同
PASS  拖选矩形被当成文字行框（上下边包住拖选点）
PASS  贴屏幕顶部 + 选「上方」→ 自动翻到下方（side=below）
PASS  贴顶时胶囊没被压出工作区
结果：8 PASS / 0 FAIL
```

> 探针本身也踩了两个坑，顺手修掉了，记在这儿免得下次再犯：
> ① 用**字节**偏移切 utf8 字符串，中文日志会被切过头（表现成"命令成功了但日志里没有"）；
> ② 取"最后一条"记录，被期间用户真划词产生的另一条顶掉 —— 改成"本次调用后的第一条"。

另外 `show_bar` 命令多了一个可选入参 `sel: [按下x, 按下y, 抬起x, 抬起y]`
（前端不传即为 `None`，老调用/老探针都不受影响），探针靠它驱真流程。

## 边界与例外

| 情形 | 行为 |
|---|---|
| 浏览器 / Electron / 记事本里**拖选** | 按「弹出位置」贴文字上方或下方（本次修复的范围） |
| 那一侧放不下 | 自动翻到另一侧；两侧都放不下按首选侧贴，clamp 兜住不出屏 |
| 贴屏幕最上沿 + 选「上方」 | 翻到下方（探针已断言） |
| **Ctrl+C** 触发 | 仍贴鼠标（那条路没有"划选范围"，是既有设计） |
| 双击选词 / Shift+方向键 | 没有拖动轨迹 → 用真光标（原生控件）或贴鼠标（浏览器） |
| 打开「横条跟随鼠标位置」 | 一律贴鼠标，本项无效（控件置灰） |
