## 一、新增：自动更新

「关于」页里多了一块**更新**区域，四样东西：

| 元素 | 作用 |
|---|---|
| ☑ **自动更新**（勾选框） | 勾着时，**每次打开软件**都自动检查一次有没有新版。没新版就**什么都不发生**；有新版会提示你。取消勾选后彻底不检查（一个网络请求都不发）。默认**勾选**。 |
| **检查更新**（按钮） | 手动点一下，立刻去查。无论有没有新版都会给回话（不会"点了没反应"）。这个按钮**不受上面那个开关限制**。 |
| **下载并安装** | 发现新版时出现。点了之后**在软件内部**把新版本下好 —— 不用跳浏览器、不用自己去 Release 页。下完自动校验、自动替换掉旧程序。 |
| **立即重启** | 装好后出现。点一下就换成新版继续用（不点也不会丢，下次开程序就是新版）。 |

配套的两件事：

- **下载完自动校验**（SHA256）—— 下到的内容不是我们发的那一份就当失败删掉，绝不把坏程序换上去。
- **换程序是"先改名、再搬新的"** —— Windows 上正在运行的 exe 删不掉但**可以改名**。
  所以旧版会被改成 `QuickSearch.exe.old` 留在原地当退路，新版就位；下次启动时自动清掉那个 `.old`。
  万一第二步失败，程序会**把旧版改回来**，保证你手上至少还有一个能用的程序。

> **自动更新这个开关的语义**（按你的口径）：它是一个**选项**，打勾才会自动检查。
> 不打勾 = 彻底不检测；想临时查一次仍然可以点「检查更新」。

## 三、自定义图标变成内置默认图标

按你的要求，把你画的那批图标**烘进程序内置资源**，成为这些引擎的**新默认图标**：

| 引擎 | 说明 |
|---|---|
| 百度 / Google / 知乎 / 淘宝 / 天猫 / 京东 | 换成你画的那一张 |
| 小红书、小红书（首页） | 共用同一张 |
| 豆瓣、豆瓣读书、豆瓣电影 | 共用同一张 |

横条、引擎面板、设置页三处同时生效（它们读同一份 `engines.json`）。
原来那 8 张内置 SVG 已移除；你配置里对应的那些"覆盖项"也清掉了 —— 现在这些图是**内置**的，
不再依赖 `%APPDATA%` 里的文件，换台电脑也照样在。

> 你另外 3 个自定义图标**保留**：`@ocr`、`@img`（功能按钮，没有"官方默认图"可回退）、
> 以及「章鱼速贴快捷输入」（你自建的热键引擎，本来就不存在默认图）。

## 四、修掉的缺陷（93 处，挑要紧的说）

### 会丢数据的

1. **剪贴板还原会把用户内容清空** —— 取词/识图借用剪贴板后用 `restore()` 还原时，
   如果快照拿到的是空表（系统在"紧接自己写完"时可能先给一张空表），
   会把用户原本复制的内容**抹掉**。这条路径被一个一直红着的单元测试精确命中，但一直没人处理。
2. **识图搜完把用户中途复制的内容覆盖回去** —— 那 1~2 秒里用户又 Ctrl+C 了别的东西，
   还原会把新的盖回旧的。现在会先比剪贴板序号，变了就放手。
3. **「清理冗余数据」会把自定义图标删光** —— 判据只看"覆盖项"，而 `icons\<引擎名>.<ext>`
   那套默认图标不在其中，于是用户点一次清理，桌面上的图标集体失效。
4. **自定义备份目录里的备份永远找不回** —— 主文件损坏时，恢复逻辑只扫数据目录，
   用户设过备份目录的话，候选位置全是空的，直接落回默认配置。
5. **明文导入可被用来改掉 WebDAV 目标并外传配置** —— 导入时没按勾选项裁剪数据。
6. **配置保存会先删旧备份再写新文件** —— 主文件写失败时备份族一份不剩。

### 会崩的

7. **识别失败信息按字节截断会 panic** —— 对方回中文错误页时截断点落在汉字中间，
   直接把整条识图线程带走。
8. **`DestroyWindow` 跨线程必然失败** —— 框选遮罩的"最后一道保险"其实一直是空的。
9. **`unreachable!` 在可扩展枚举上** —— 加个引擎类型就可能 panic 掉整个程序。

### 功能静默失效的（"点了没反应"）

10. **设置页整个 AI 抠图模块被吞进 `boot()` 作用域** —— 15 个函数成了局部函数，
    「打开图标编辑器后再换图标」这类开关永远不会刷新状态。
11. **开关点了列表不重画** —— 代码里调了一个全项目不存在的 `renderAll()`。
12. **`win+…` 收藏夹热键永远不触发** —— 设置页允许录，后端却把 Win 键丢掉了。
13. **腾讯云 OCR 一直不可用** —— 签名里写的 Content-Type 和实际发出去的不一致，
    服务端必然判签名失败。
14. **没配在线密钥时「能框选、框完必然失败」** —— 放行判断用了本地兜底名单，识别时却没用。
15. **深色模式下几个纯黑品牌图标是黑的**（等于隐形）—— 反白规则被同特异度的规则整条覆盖。

### 性能 / 卡顿

16. **引擎过滤框敲第一个字卡一两秒** —— 同步创建 777 个格子，每格还跑一次 canvas 像素测量。
17. **每次配置广播重建 777 行引擎列表**，还会把滚动位置弹回顶部。
18. **鼠标钩子每秒上千条移动事件全塞进队列**，回调里还写日志。
19. **AI 模型每次抠图都重新加载**（`rmbg-full` 是 168MB，每次白付 270ms）。
20. **同一张图解码两遍、base64 编码两遍**。
21. **拖拽时每个像素级动作都发一次布局 IPC**。
22. **抓屏缓冲先清零再被覆盖写**（大屏上是上百 MB 的无效 memset）。
23. **玻璃渲染没有 WebGL 上下文丢失/恢复处理** —— GPU 重置后玻璃永久空白，只能重启。

### 中文输入体验

24. **横条上两个输入框都没有输入法保护** —— 打拼音按回车选词，会直接拿半截拼音去搜并收起横条。

完整逐条清单（93 处，含位置与修法）见仓库里的审计报告。

## 五、安装

单文件，无需任何运行时：

1. 下载下面的 `QuickSearch.exe`；
2. 放到你想放的位置（建议单独一个文件夹，别放系统目录）；
3. 双击运行。**首次会请求管理员权限** —— 这是必要的（不然 Ctrl+C 送不进同样是管理员的程序）。

> 升级到这一版有两条路：
> · 直接用新版 exe 覆盖旧的（配置与图标都在 `%APPDATA%\QuickSearch`，不会丢）；
> · 或者用**这一版之后**的「自动更新」—— 以后就不用自己手动换了。

## 六、关于「AI 抠图」的模型（重要）

**AI 抠图的模型文件不随本版本上传**（一共 300+ MB，每个小版本都重传一遍不划算）。
它们固定挂在 **v1.1.1** 那个发布页上，程序会自动去那里下：

👉 **https://github.com/QQQOrange/QuickSearch/releases/tag/v1.1.1**

里面有：

| 文件 | 体积 | 说明 |
|---|---|---|
| `u2netp.onnx` | 4.4 MB | **推荐**。实测在图标上最准，也最快 |
| `rmbg-quantized.onnx` | 42 MB | 人像/产品照片效果好 |
| `rmbg-fp16.onnx` | 84 MB | 比量化版准一点 |
| `rmbg-full.onnx` | 168 MB | 官方原始精度 |
| `onnxruntime.dll` | 11.8 MB | 推理运行库，随模型一起下 |

**你不用自己去下载** —— 在「设置 → 通用 → AI 抠图」里点某个模型的「下载」，
程序会把模型**和运行库**一起下到 `<程序目录>\抠图模型\`，下完直接可用、不用重启。
不打开这个功能的话，这些一个都不下。

> 「关于」页的 AI 抠图那一段也会显示"模型在哪个页面下载"，那里是同一个来源，不会和实际地址脱节。

## 九、已知限制

- **自动更新需要能访问 GitHub**。国内网络下 `github.com` 时通时不通；
  查不到更新时不会静默失败，会给一句人话（例如"GitHub 接口暂时限流了，过一会儿再试"）。
  限流那一层已经处理：日常检查走的是**不消耗 API 额度**的路径（从 302 里取版本号），
  只有确实发现新版时才去调 API 拿下载地址。
- **替换程序需要写权限**。装在 `Program Files` 且当前不是管理员时，替换会失败 ——
  失败会明确告知，并且**旧程序原样可用**（不会把程序换成打不开的状态）。
- 引擎数据里的 URL 与图标版权归各站点所有，本项目只作跳转索引。

## 十、校验值

```
文件:   QuickSearch.exe
大小:   12.28 MB (12,877,312 字节)
MD5:    F707D0DC775216E53F00626193E03B07
SHA256: 8591BA9B830DE9BDAEB810202C74E6921DFC78F48B5D88633543AF4D4A6FC05B
```

核对方式（PowerShell）：

```powershell
Get-FileHash .\QuickSearch.exe -Algorithm SHA256
```

> ⚠ 上面那行 **`SHA256:` 就是自动更新用的校验值** —— 程序下载完更新包会拿它比对，
> 不一致就当失败删掉。所以这一行不能改格式、也不能删。
