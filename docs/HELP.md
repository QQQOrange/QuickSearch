# Quick Search 使用帮助

适用版本：**v2.6.0**（Windows 10 / 11）
返回：[项目介绍](../README.md) ｜ [English](HELP.en.md)

---

## 1. 这是什么

一个常驻托盘的划词工具。选中文字后，屏幕上方弹出一条横条，点一颗图标就把这段文字交给
对应的网站 / 软件 / 快捷键处理。除此之外还带屏幕文字识别、翻译、截图识图、收藏夹和加密备份。

**它没有主窗口**——所有交互都从托盘图标和横条进入。

---

## 2. 安装与首次运行

1. 从 [Release 页面](https://github.com/QQQOrange/QuickSearch/releases/latest) 下载 `QuickSearch.exe`。
2. 放到一个单独文件夹里（例如 `D:\软件\QuickSearch\`），双击运行。
3. 首次运行**不会出现窗口**，请看任务栏右下角托盘区（可能折叠在 `^` 按钮里）。

> 程序是便携的：配置、图标、日志都会生成在 exe 同级的 `Quick search data\` 目录里。

---

## 3. 基本使用

| 操作 | 效果 |
|---|---|
| 在任意软件里**选中文字** | 横条自动弹出 |
| **Ctrl + 双击** | 手动唤出横条 |
| **Ctrl + C**（默认） | 唤出**网格页**（格子面板），和划词横条是两套界面 |
| 点击横条上的图标 | 用该引擎搜索 / 打开 |
| **双击托盘图标** | 打开设置 |
| **右键托盘图标** | 菜单（设置、退出等） |

触发方式与快捷键都在 **设置 → ⚙️ 通用** 里调整。

如果横条在你不想它出现的地方弹出，到 **设置 → 🚫 范围** 里把那个程序加入黑名单。

### 两种横条的区别（重要）

程序里有**两套**弹层，内容、样式、配置都分开，互不影响：

| | 划词横条 | 网格页 |
|---|---|---|
| 怎么叫出来 | 选中文字 / Ctrl+双击 | 按快捷键（默认 **Ctrl+C**） |
| 长什么样 | 一条细横条，从左到右排引擎 | 一块网格面板，格子按行列排 |
| 放什么 | 横条成员（设置 → 🔎 引擎） | **自己单独一份**内容（见下） |
| 点下去搜什么 | 选中的那段文字 | 剪切板里**已有的**文字；没有就打开该引擎首页 |

**网格页怎么配**（设置 → 🧩 **网格页设置**）：这一栏分成「实时预览 / 外观 / 功能 / 格子内容」四块。

- **实时预览**：这里显示的就是网格页本身 —— 它加载的是网格页同一份样式表、同一套结构，
  所以布局、尺寸、间距、圆角、颜色、阴影都跟按快捷键弹出来的**完全一致**。
  改下面任何一项，预览立刻跟着变。预览框是**固定高度**的：格子调得再高也是框内滚动，
  不会把整页顶长（这样你改一个数字时，下面的控件不会跑位）。
  - **拖右边缘 / 下边缘 / 右下角**可以直接改格子宽高，数字框跟着动，停手自动保存；
  - **直接拖动预览里的格子**就能换位置，和「格子内容」列表里的拖动排序同步。
- **外观**：行 1–10 × 列 1–10（3×3 / 3×4 / 4×4 都行）；格子宽 40–260 px、高 40–200 px；
  格子间距 0–24 px；格子圆角 0–24 px。颜色/阴影/磨砂这些跟「横条外观」共用一套，不单独配色。
  **格子文字**：选「图标 + 名称」还是「只显示图标」—— 只显示图标更清爽，格子也能做得更矮；
  改完立即生效（不用点「保存外观」）。这是**默认样式**，单项可以单独覆盖（见下面「格子内容」）。
  - **行数会自动增长**：上面填的「行」是**最少几行**。3 行 3 列放满 9 项后，
    加第 10 项时网格页会自己多出一行（4 行 12 格）；内容删回去，多出来的行也会自动收掉。
  - **格子矮了也不会只剩图标**：低于 66px 时改成"图标在左、名称在右"的紧凑排版，
    名称照样看得见（以前是直接藏掉）。
- **功能**：
  - **启用网格页**：关掉后快捷键不再唤起它，内容与配置都保留；
  - **点空白格子可添加内容**：关掉后空位只作占位，防止误触；
  - **点格子时的行为**：`有文字就搜`（默认）或 `总是打开引擎首页`（把网格当书签面板）；
  - **唤起快捷键**：默认 `ctrl+c`，可改 `ctrl+shift+g` / `alt+space` 等。改了之后
    **Ctrl+C 不再生效**；和「收藏夹热键」或 `Ctrl+Alt+O` 撞车会提示冲突并拒绝保存。
  - **快捷键自检**：按了没反应时点它，会告诉你卡在哪一步（写法不对 / 总开关关了 /
    已暂停 / 当前程序在黑名单）。
- **格子内容**：和横条那份**完全分开**。可逐项添加，也可「从横条导入」；
  **按住任意一项上下拖动**即可排序，松手即保存（在预览里拖格子也一样）。格子数 = 行 × 列，
  行数会随内容自动增长。
  **每行右侧的下拉框**是这个单元格的显示样式：**跟随默认 / 图标+名称 / 只图标 / 只名称** ——
  默认样式在「外观 → 格子文字」里，这里只覆盖这一项。比如把智能直达那一格设成「只名称」，
  格子里就只显示它的备注（网页标题）。
  「＋ 添加内容」里除了搜索引擎，还有**文字识别模型 / 识图模型 / 翻译模型**三组
  （搜「百度」能同时看到百度搜索和百度 OCR）。**模型条目是"绑定具体一家"的**：
  点「百度 OCR」加进网格的就是"这一格固定用百度 OCR"，点下去只会跑它，
  不会回退到设置里的全局默认；不同的模型各占一格、可以同时存在。
  另外还有「包裹符号」这类**功能格子**：
  - **包裹符号**：点一下打开符号菜单（“” 《》 【】 等），把选中的文字**套上 / 拆掉 / 换一对**，
    和横条上那颗 `[ ]` 是同一件事；
  - **文字识别 / 识图 / 翻译**：点一下就是框选识别、按图搜索、翻译当前文字；
    用哪一家模型由 设置 → 附加功能 里选中的那个决定（列表里带「当前使用」的就是它）。
- **所有改动立即生效**，不用重启。

### 右下角提示当前功能

用**划词横条 / 网格页 / 文字识别 / 翻译 / 识图**时，屏幕右下角会弹一条**应用自己画的**小提示：

- 内容：「正在使用：<功能名> · <你正在用的软件>」；
- 时机：功能**真的启动**才弹（被"已暂停 / 黑名单 / 功能已关闭"拦掉的不弹）；
- 显示时长：**设置 → 通用 → 「提示显示时长」**可调（1~15 秒，默认 3 秒）；
- 频率：同一软件里的同一功能 **10 秒内只提示一次**（横条会跟着鼠标动被反复唤起，不节流会连弹）；
- 不想要就关掉：**设置 → 通用 → 「右下角提示当前功能」**（默认开）。

> 这不是 Windows 的系统通知，而是程序自己的小窗：圆角、跟随深色/浅色主题，
> 不抢焦点、不进任务栏、**鼠标穿透**（点下去落到下面的软件上，不会挡住任何操作）。

**在网格页上直接操作**：

- 右上角有两颗按钮：**✏️ 编辑**（进入编辑模式，每格右上角出现 **×**，点它把这格内容移出；
  再点一下退出）和 **⚙ 设置**（一键跳到这个设置页）。
- **编辑态可以直接拖边框调大小**：进入编辑后，面板右边缘 / 下边缘 / 右下角各有一条
  拖动带（和设置页预览里那三个一样），拖完自动保存，不用再回设置页改数字。
- 点**空白格子**会弹出「添加内容」面板，直接挑一项填进那一格。面板按
  **大类（内置功能 / 智能直达 / 收藏夹 / 模型 / 网页引擎 / 软件引擎 / 快捷键）→ 主题组 → 分类**
  三层归类，顶部有关键词搜索；已经在网格里的项会打勾置灰。
  **三个引擎大类默认收起**（网页引擎 / 软件引擎 / 快捷键引擎），点一下才展开它的
  主题组和分类 —— 和横条「更多引擎」是同一个节奏；搜索时自动展开命中部分。
  **拖右下角可以改这个面板的长宽，拖完就记住**，下次打开（包括重启软件后）还是你调的大小。
- 设置页里也有同一个窗口：**网格页设置 → 格子内容 → ＋ 添加内容**（顶部有搜索框，
  按「附加功能 / 智能直达 / 引擎」分组，图标和别处一致）。
- 更快的一条路：在**引擎列表**、**智能直达列表**、**包裹符号页**上直接点「加到网格页 / ＋网格」，
  再点一次就是移出。
- 格子上显示的都是**看得懂的名字**：内部名 `@ocr`、`@//ocr/` 显示成「文字识别」，
  `@trans` 显示成「翻译」，智能直达 / 外部软件 / 收藏夹直接显示你自己起的名字。
- 如果你刚选过一段文字再按快捷键，点搜索引擎会**直接拿这段文字去搜**（不需要先复制）；
  「点格子行为」设成"总是打开首页"时不带文字。

> 网格页的主题跟着「外观」里的横条主题走（亮/暗/跟随系统），不需要单独配色。

### 包裹符号（给选中的文字套上一对符号）

入口在 **设置 → ➕ 附加功能 → 🧷 包裹符号**，页面上有「添加到横条 / 添加到网格页」，
加进去之后横条或网格页上就有这颗 **`[ ]`** 按钮。

选中一段文字后，横条上会出现一颗 **`[ ]`** 按钮 —— 点它把这段文字套成一对符号，再点一次拆掉。

| 分组 | 符号 | 名称 |
|---|---|---|
| 引号 | `“文”` `‘文’` `「文」` | 双引号 / 单引号 / 直角引号 |
| 特型 | `《文》` `〈文〉` `【文】` | 书名号 / 单书名号 / 方头括号 |
| 括号 | `（文）` `[文]` `{文}` | 圆括号 / 方括号 / 花括号 |
| 英文 | `"文"` `'文'` `` `文` `` | 英文双引号 / 英文单引号 / 反引号 |

**怎么用**

1. 选中文字 → 横条弹出 → 点 `[ ]`；
2. 菜单里点一组符号（也可以在菜单开着时按 **1–9** 直选第几组）；
3. 结果**立刻复制到剪贴板**，提示条上会写「已包裹（已复制）」；
4. 回到原处 **Ctrl+V 覆盖**原文字即可。

**反复点同一组 = 来回切换**

| 当前文字 | 你点的 | 结果 |
|---|---|---|
| `人工智能` | 双引号 | `“人工智能”` |
| `“人工智能”` | 双引号 | `人工智能`（拆掉） |
| `““人工智能””` | 双引号 | `人工智能`（**套了几层一次拆干净**） |
| `《人工智能》` | 双引号 | `“人工智能”`（**换外层**，不会叠成 `“《…》”`） |
| `人工智能` | 方括号 | `[人工智能]` |

首尾的空白和换行**保留在符号外面**（选中的是整段缩进文字时不会被打乱）；只有一半符号
（比如只有结尾的 `”`）不算"已经包过"，会照常包一层。

**没有选中文字时**：`[ ]` 按钮**不出现**（和 🔗 / 📁 / 📄 同一套口径）；万一通过其它途径触发，
会提示「先选中一段文字，再来包符号」，不会产出 `“”` 这种空壳。

**和其他编辑操作一致的地方**

- 它和其它按钮一样**只读当前这段文字**，改的是"要复制出去的结果"，不会去改动别的程序的选区；
- 结果统一落在**剪贴板**（与"复制取词"同一个出口），所以按 Esc 收菜单不会影响已经复制的内容；
- 菜单开着时 **Esc 只收菜单**，不会把整条横条关掉；换选另一段文字会自动收起菜单，避免包错内容。

> **它会直接改掉原处的文字**（v2.6.2 起）：点符号后程序把焦点交还给原来那个软件、
> 用一次粘贴覆盖掉你选中的那段。结果同时留在剪贴板里，所以想反悔就按 **Ctrl+Z**
> （或把剪贴板里的内容粘回去）。若撤销过、或原来那个窗口已经不在，它会**只复制不写入**，
> 并在菜单里说明原因 —— 绝不在你的文档里乱改。

### 按应用绑定（给某个软件单独配一套横条 / 网格页）

设置 → **按应用**。

- 填**进程名**（任务管理器 → 详细信息里的「名称」列，如 `chrome.exe`），或点
  「取当前应用」抓你刚才在用的那个软件；支持 `*` 通配（`*chrome*` 能命中 Chrome 的各种进程）。
- **横条**与**网格页**是两套独立配置：只给 Chrome 换横条，它的网格页照旧；反过来也一样。
- 横条那边配的是**一整份内容**（整份取代默认横条）；网格页那边配的是**指向某一页**。
- 优先级：**该应用的专项配置 > 默认配置**。下面几种情况一律回退默认，并在面板上用红字
  写清原因：
  - 没配过 / 进程名对不上；
  - 专项内容被清空；
  - 专项里的东西全都认不出来了（例如对应引擎已被删除）；
  - 绑的那一页被删了 / 那一页是空的。
- 改完**立刻生效**，不用重启；下次在那个软件里唤起就是这一套。
- 多条绑定同时命中时：**精确 > 通配；同为通配则模式更长的优先；仍并列就先配的优先**。
- 面板底部「已配置的应用」把两类绑定并在一起列出，可以一键「配置」或「清除」。

## 4. 文字识别（OCR）

1. 点横条上的 **OCR** 按钮（如果你换过图标，显示的就是你自己那张图）。
2. 框选屏幕区域，松开鼠标后开始识别。
3. 识别结果在独立窗口展示；支持**多家引擎同时识别**，并排多框对照。

要点：

- **默认使用本地引擎**，离线、免费、即时，不消耗任何在线额度。
- 需要更高精度时可以到 **设置 → 🔤 文字识别** 里切换或添加在线引擎（多数按量计费）。
- 可以把多家在线引擎勾选进「同时识别」，但注意那会产生对应次数的调用。

## 5. 翻译

选中文字后在横条上点翻译按钮即可。引擎、凭据、是否流式输出都在 **设置 → 🌐 翻译** 里。

---

## 6. 截图识图

点横条上的识图按钮 → 框选屏幕区域 → 用所选引擎以图搜图。
引擎与凭据在 **设置 → 🖼 识图**。

---

## 7. 收藏夹

**设置 → ⭐ 收藏夹** 里可以建两级目录，条目支持文字、图片、富文本，可拖拽排序。
收藏夹的面板可以从托盘菜单或快捷键唤出。

## 8. 智能直达

把常用的**软件、网址、本地文件**收进横条，点一下就打开 —— 只需要录一个地址，类型由程序自己认。

### 加一条入口

1. 设置 → **🎯 直达**；
2. 在输入框里粘一个地址，回车（或点「识别并添加」）；
3. 程序会判断它属于哪一类，并把名称 / 备注 / 图标先填好 ——
   **网址会自动抓网页标题填进备注**（抓不到就留空，预览卡里有「重新抓标题」可再试一次）；
4. 想改就在预览卡里改，确认后点**保存**。

> **显示名看哪个字段？** 优先级是 **备注 > 名称 > 目标**：
> 设了备注，列表/横条/网格上显示的就是备注（备注通常是网页标题，比域名好认）；
> 只有备注为空时才显示名称。

能直接粘的东西：

| 你粘的 | 会被认成 | 说明 |
|---|---|---|
| `https://example.com`、`example.com` | 网址 | 没写协议自动补 `https://` |
| `D://Tools//App.exe`、`notepad` | 软件 | 支持 `.exe/.lnk/.bat/.cmd/.msi`；只写名字会去 `PATH` 里找 |
| `%USERPROFILE%\Desktop\清单.xlsx` | 文件 | 支持文件与文件夹，`%变量%` 和 `~` 都会展开 |

**保存前一定先校验**：网址检查格式（并尝试抓网页标题），软件/文件检查路径是否真的存在。校验不过会直接告诉你原因，不会存一条点了没反应的空壳。

### 备注是自动填的

- **网址**：抓网页 `<title>`（3 秒超时，抓不到就用域名，不会因此拦着不让你存）；
- **软件**：取程序名（`notepad.exe` → `notepad`）；
- **文件**：取文件名（带扩展名）。

三条都能手动改。

### 图标

留空就用**按类型自动选的默认图标**：

| 类型 | 默认图标 |
|---|---|
| 网址 | 地球 |
| 文件夹 | 文件夹 |
| 软件（exe/lnk/bat…） | 程序自己的图标（从 exe 里抠出来），抠不到就用软件图标 |
| 文本 / Markdown / 配置 | 文档 + 文字行 |
| 图片 | 相框 |
| 视频 | 播放器 |
| 音频 | 音符 |
| PDF | 带 PDF 字样的文档 |
| 压缩包 | 压缩包 |
| 代码文件 | `<>` |
| Office 文档 | 文档 + 列表 |
| 其他 | 通用文件 |

类型是**按目标实时判的**（目录看是不是文件夹、文件看扩展名），所以把 `.txt` 改名成
`.mp4` 之后图标会自己跟着变，不用重设。

要自定义有两种方式：

- **选本地图片**（png / jpg / ico / svg / webp / gif / bmp，≤3MB）；
- **填图片地址**（`http(s)://…`）。填地址时程序会把图**下载下来存进配置**，所以断网、图床挂掉都不影响横条显示。

### 固定到横条、排序、编辑、删除

- **固定到横条**：那一格就出现在横条上，点一下直接打开；
- **↑ / ↓**：调整顺序（到头了按钮会灰掉）；
- **编辑**：改名称、备注、目标、图标；只改目标时会**重新识别和校验**；
- **试一下**：立刻打开，路径失效这类问题当场就能看见原因；
- **删除**：连横条上那一格一起收掉，不会留下点了没反应的死格子。

上限 200 条。

### 数据、同步与备份

智能直达存在配置里（`shortcuts`），所以**跟着整份配置一起走**：

- **本地备份 / 恢复**（`.QuickSearch`）：整份配置含直达入口，恢复即可回到那个时间点；
- **WebDAV 同步**：与其它配置项同一份文件、同一时机（启动时比时间、退出时上传），没有单独的开关；
- **导入 / 导出**：导出分组里新增 **「智能直达」**（含链接/路径、名称、备注、图标）。这一组默认**不勾选**（路径会暴露本机目录结构），要一起带走就手动勾上。

**恢复/导入时的容错口径**（防止手改过的备份把配置弄坏）：

| 情况 | 处理 |
|---|---|
| 同一条重复出现（同类目标、忽略网址结尾斜杠与路径大小写） | 只留第一条 |
| `id` 撞车 | 后来的丢掉（否则横条同一根哨兵会指到两条） |
| 缺 `id` / 缺目标 / 类型不是 app·url·file | 整条跳过，不猜 |
| 名称空着 | 用目标地址顶上，至少横条上有字 |
| 超过 200 条 | 只收前 200 条 |

导入/恢复是**整段替换**（和恢复备份的语义一致：回到那个时间点），不会把新旧两条列表混在一起。

### 常见问题

**点了提示「路径不存在或已被移动」** —— 目标被移动/删除了，点「编辑」重新指向即可。

**提示「已经指向同一个目标了」** —— 同类目标不允许重复；想加两条不同用途的，先改其中一条的目标。

**浏览器没打开** —— 程序只是把网址交给系统默认浏览器；打不开多半是系统里没有默认浏览器或关联被破坏。

**横条上图标是裂的** —— 说明这条的图标数据坏了，点「清空图标」退回首字徽标，再重新选一张。

## 9. 自定义图标

任何引擎、OCR 按钮、翻译按钮、收藏夹条目都可以换成自己的图标：

1. 在 **设置 → 🔎 引擎** 里找到目标条目 → 点图标 → 选一张图。
2. 想恢复默认：同一个位置点「恢复默认」。

两条机制要知道：

- **图标会跟着新版本走**。升级时程序会自动继承你之前的自定义图标，不用重新设。
- 在 `Quick search data\icons\` 里放一张**文件名等于引擎名**的图（如 `百度.png`），
  该引擎就会用它——不必逐个去设置里挑。

## 10. 备份、恢复与同步

### 本地备份

**设置 → ☁️ 备份** → 手动备份，产物在 exe 同级的 `QuickSearch back\`，文件名形如
`config(2026-10-30 18-11-57).QuickSearch`。也支持按计划自动备份。

### 备份密码（重要）

设置了备份密码后，备份文件才能换机器恢复；**密码丢了就解不开，无法找回**。
换了 Windows 用户或重装系统后，如果提示「这份备份设了密码，但本机还没填」，
请到 **设置 → ☁️ 备份** 填入当时的密码再恢复。

### WebDAV 同步

在 **设置 → ☁️ 备份** 里填服务器地址、账号、密码，可选择启动时同步、退出时上传。
多台机器同步前建议先各自备份一次。

### 换机器怎么做

推荐：旧机「备份 → 导出」→ 新机「恢复」。
不建议直接拷 `config.json`，它依赖本机的 DPAPI 密钥，换机后可能解不开。

## 12. 常见问题

**双击没反应 / 打不开？**
这是托盘程序，没有主窗口。看托盘区（含 `^` 折叠区）有没有图标；已经在运行时再双击 exe
只会静默退出，这是正常的（避免多实例抢热键）。

**托盘里找不到图标？**
点任务栏的 `^` 展开隐藏图标；也可以在系统设置里把它的托盘图标设为「始终显示」。

**图标不显示 / 显示成文字？**
说明那张图没读到。检查 `Quick search data\icons\` 里文件是否存在；自定义图标可以在设置里
点「恢复默认」后重设。

**OCR 提示额度用完？**
如果你用过在线引擎，可能是它的免费额度耗尽了。切到本地引擎即可继续使用，无需联网。

**升级后设置还在吗？**
在。配置格式与目录位置都没变，覆盖 exe 即可；自定义图标也会自动继承。

**怎么彻底卸载？**
退出程序 → 删除 exe 与 `Quick search data`、`QuickSearch back` 两个目录 →
如需，删掉开机自启项（任务管理器 → 启动 → Quick Search，或设置里的开机自启开关）。
