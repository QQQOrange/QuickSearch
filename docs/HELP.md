# Quick Search 使用帮助

适用版本：**v2.3.0**（Windows 10 / 11）
返回：[项目介绍](../README.md) ｜ [English](HELP.en.md)

---

## 1. 这是什么

一个常驻托盘的划词工具。选中文字后，屏幕上方弹出一条横条，点一颗图标就把这段文字交给
对应的网站 / 软件 / 快捷键处理。除此之外还带屏幕文字识别、翻译、截图识图、收藏夹和加密备份。

**它没有主窗口**——所有交互都从托盘图标和横条进入。

---

## 2. 安装与首次运行

1. 从 [Release 页面](https://github.com/QQQOrange/QuickSearch/releases/latest) 下载 `QuickSearch.exe`。
2. 放到一个单独文件夹里（例如 `D:\软件\QuickSearch\`），双击运行。
3. 首次运行**不会出现窗口**，请看任务栏右下角托盘区（可能折叠在 `^` 按钮里）。

> 程序是便携的：配置、图标、日志都会生成在 exe 同级的 `Quick search data\` 目录里。

---

## 3. 基本使用

| 操作 | 效果 |
|---|---|
| 在任意软件里**选中文字** | 横条自动弹出 |
| **Ctrl + 双击** | 手动唤出横条 |
| **Ctrl + C**（默认） | 唤出**网格页**（格子面板），和划词横条是两套界面 |
| 点击横条上的图标 | 用该引擎搜索 / 打开 |
| **双击托盘图标** | 打开设置 |
| **右键托盘图标** | 菜单（设置、退出等） |

触发方式与快捷键都在 **设置 → ⚙️ 通用** 里调整。

如果横条在你不想它出现的地方弹出，到 **设置 → 🚫 范围** 里把那个程序加入黑名单。

### 两种横条的区别（重要）

程序里有**两套**弹层，内容、样式、配置都分开，互不影响：

| | 划词横条 | 网格页 |
|---|---|---|
| 怎么叫出来 | 选中文字 / Ctrl+双击 | 按快捷键（默认 **Ctrl+C**） |
| 长什么样 | 一条细横条，从左到右排引擎 | 一块网格面板，格子按行列排 |
| 放什么 | 横条成员（设置 → 🔎 引擎） | **自己单独一份**内容（见下） |
| 点下去搜什么 | 选中的那段文字 | 剪切板里**已有的**文字；没有就打开该引擎首页 |

**网格页怎么配**（设置 → ⚙️ 通用 → 「网格页（Ctrl+C）」）：

- **快捷键**：默认 `ctrl+c`，可以改成 `ctrl+shift+g`、`alt+space` 等任意组合。
  改了之后 **Ctrl+C 就不再唤起它**。如果组合和「收藏夹热键」或「Ctrl+Alt+O 框选识别」
  撞车，会直接提示冲突、不予保存。
- **行列**：1–10 行 × 1–10 列，3×3 / 3×4 / 4×4 都行。
- **单元格尺寸**：宽 40–260 px、高 40–200 px。
- **格子内容**：和横条那份**完全分开**。可以一项项添加，也可以点「从横条导入」抄一份过来；
  列表里**按住任意一项上下拖动**就能排序，**松手即保存**。格子数 = 行 × 列，多出来的不显示，
  空位显示虚框。
- 所有改动**立即生效**，不用重启；点「预览」可以马上看到效果。

> 网格页的主题跟着「外观」里的横条主题走（亮/暗/跟随系统），不需要单独配色。

## 4. 文字识别（OCR）

1. 点横条上的 **OCR** 按钮（如果你换过图标，显示的就是你自己那张图）。
2. 框选屏幕区域，松开鼠标后开始识别。
3. 识别结果在独立窗口展示；支持**多家引擎同时识别**，并排多框对照。

要点：

- **默认使用本地引擎**，离线、免费、即时，不消耗任何在线额度。
- 需要更高精度时可以到 **设置 → 🔤 文字识别** 里切换或添加在线引擎（多数按量计费）。
- 可以把多家在线引擎勾选进「同时识别」，但注意那会产生对应次数的调用。

---

## 5. 翻译

选中文字后在横条上点翻译按钮即可。引擎、凭据、是否流式输出都在 **设置 → 🌐 翻译** 里。

---

## 6. 截图识图

点横条上的识图按钮 → 框选屏幕区域 → 用所选引擎以图搜图。
引擎与凭据在 **设置 → 🖼 识图**。

---

## 7. 收藏夹

**设置 → ⭐ 收藏夹** 里可以建两级目录，条目支持文字、图片、富文本，可拖拽排序。
收藏夹的面板可以从托盘菜单或快捷键唤出。

---

## 8. 智能直达

把常用的**软件、网址、本地文件**收进横条，点一下就打开 —— 只需要录一个地址，类型由程序自己认。

### 加一条入口

1. 设置 → **🎯 直达**；
2. 在输入框里粘一个地址，回车（或点「识别并添加」）；
3. 程序会判断它属于哪一类，并把名称 / 备注 / 图标先填好；
4. 想改就在预览卡里改，确认后点**保存**。

能直接粘的东西：

| 你粘的 | 会被认成 | 说明 |
|---|---|---|
| `https://example.com`、`example.com` | 网址 | 没写协议自动补 `https://` |
| `D://Tools//App.exe`、`notepad` | 软件 | 支持 `.exe/.lnk/.bat/.cmd/.msi`；只写名字会去 `PATH` 里找 |
| `%USERPROFILE%\Desktop\清单.xlsx` | 文件 | 支持文件与文件夹，`%变量%` 和 `~` 都会展开 |

**保存前一定先校验**：网址检查格式（并尝试抓网页标题），软件/文件检查路径是否真的存在。校验不过会直接告诉你原因，不会存一条点了没反应的空壳。

### 备注是自动填的

- **网址**：抓网页 `<title>`（3 秒超时，抓不到就用域名，不会因此拦着不让你存）；
- **软件**：取程序名（`notepad.exe` → `notepad`）；
- **文件**：取文件名（带扩展名）。

三条都能手动改。

### 图标

留空就用默认（软件自动从 exe 里抠图，网址/文件用首字徽标）。

要自定义有两种方式：

- **选本地图片**（png / jpg / ico / svg / webp / gif / bmp，≤3MB）；
- **填图片地址**（`http(s)://…`）。填地址时程序会把图**下载下来存进配置**，所以断网、图床挂掉都不影响横条显示。

### 固定到横条、排序、编辑、删除

- **固定到横条**：那一格就出现在横条上，点一下直接打开；
- **↑ / ↓**：调整顺序（到头了按钮会灰掉）；
- **编辑**：改名称、备注、目标、图标；只改目标时会**重新识别和校验**；
- **试一下**：立刻打开，路径失效这类问题当场就能看见原因；
- **删除**：连横条上那一格一起收掉，不会留下点了没反应的死格子。

上限 200 条。

### 数据、同步与备份

智能直达存在配置里（`shortcuts`），所以**跟着整份配置一起走**：

- **本地备份 / 恢复**（`.QuickSearch`）：整份配置含直达入口，恢复即可回到那个时间点；
- **WebDAV 同步**：与其它配置项同一份文件、同一时机（启动时比时间、退出时上传），没有单独的开关；
- **导入 / 导出**：导出分组里新增 **「智能直达」**（含链接/路径、名称、备注、图标）。这一组默认**不勾选**（路径会暴露本机目录结构），要一起带走就手动勾上。

**恢复/导入时的容错口径**（防止手改过的备份把配置弄坏）：

| 情况 | 处理 |
|---|---|
| 同一条重复出现（同类目标、忽略网址结尾斜杠与路径大小写） | 只留第一条 |
| `id` 撞车 | 后来的丢掉（否则横条同一根哨兵会指到两条） |
| 缺 `id` / 缺目标 / 类型不是 app·url·file | 整条跳过，不猜 |
| 名称空着 | 用目标地址顶上，至少横条上有字 |
| 超过 200 条 | 只收前 200 条 |

导入/恢复是**整段替换**（和恢复备份的语义一致：回到那个时间点），不会把新旧两条列表混在一起。

### 常见问题

**点了提示「路径不存在或已被移动」** —— 目标被移动/删除了，点「编辑」重新指向即可。

**提示「已经指向同一个目标了」** —— 同类目标不允许重复；想加两条不同用途的，先改其中一条的目标。

**浏览器没打开** —— 程序只是把网址交给系统默认浏览器；打不开多半是系统里没有默认浏览器或关联被破坏。

**横条上图标是裂的** —— 说明这条的图标数据坏了，点「清空图标」退回首字徽标，再重新选一张。

## 9. 自定义图标

任何引擎、OCR 按钮、翻译按钮、收藏夹条目都可以换成自己的图标：

1. 在 **设置 → 🔎 引擎** 里找到目标条目 → 点图标 → 选一张图。
2. 想恢复默认：同一个位置点「恢复默认」。

两条机制要知道：

- **图标会跟着新版本走**。升级时程序会自动继承你之前的自定义图标，不用重新设。
- 在 `Quick search data\icons\` 里放一张**文件名等于引擎名**的图（如 `百度.png`），
  该引擎就会用它——不必逐个去设置里挑。

## 10. 备份、恢复与同步

### 本地备份

**设置 → ☁️ 备份** → 手动备份，产物在 exe 同级的 `QuickSearch back\`，文件名形如
`config(2026-10-30 18-11-57).QuickSearch`。也支持按计划自动备份。

### 备份密码（重要）

设置了备份密码后，备份文件才能换机器恢复；**密码丢了就解不开，无法找回**。
换了 Windows 用户或重装系统后，如果提示「这份备份设了密码，但本机还没填」，
请到 **设置 → ☁️ 备份** 填入当时的密码再恢复。

### WebDAV 同步

在 **设置 → ☁️ 备份** 里填服务器地址、账号、密码，可选择启动时同步、退出时上传。
多台机器同步前建议先各自备份一次。

### 换机器怎么做

推荐：旧机「备份 → 导出」→ 新机「恢复」。
不建议直接拷 `config.json`，它依赖本机的 DPAPI 密钥，换机后可能解不开。

## 11. 数据目录

| 路径 | 内容 |
|---|---|
| `<exe 同级>\Quick search data\config.json` | 配置（加密存储） |
| `<exe 同级>\Quick search data\icons\` | 你的自定义图标 |
| `<exe 同级>\Quick search data\log.txt` | 运行日志（排障用） |
| `<exe 同级>\QuickSearch back\` | 备份文件 |

整个文件夹可以整体拷走。**删除数据目录等于恢复出厂设置。**

## 12. 常见问题

**双击没反应 / 打不开？**
这是托盘程序，没有主窗口。看托盘区（含 `^` 折叠区）有没有图标；已经在运行时再双击 exe
只会静默退出，这是正常的（避免多实例抢热键）。

**托盘里找不到图标？**
点任务栏的 `^` 展开隐藏图标；也可以在系统设置里把它的托盘图标设为「始终显示」。

**图标不显示 / 显示成文字？**
说明那张图没读到。检查 `Quick search data\icons\` 里文件是否存在；自定义图标可以在设置里
点「恢复默认」后重设。

**OCR 提示额度用完？**
如果你用过在线引擎，可能是它的免费额度耗尽了。切到本地引擎即可继续使用，无需联网。

**升级后设置还在吗？**
在。配置格式与目录位置都没变，覆盖 exe 即可；自定义图标也会自动继承。

**怎么彻底卸载？**
退出程序 → 删除 exe 与 `Quick search data`、`QuickSearch back` 两个目录 →
如需，删掉开机自启项（任务管理器 → 启动 → Quick Search，或设置里的开机自启开关）。
