# Quick Search v1.5.21

## 修复：横条一出现就是半透明的

### 问题
划词弹出的横条**一出现就是淡的**，而预期是「先不透明，过一段时间才渐渐变透明」。
即使设置里调过「悬停前透明度」，看起来也没生效。

### 根因
代码里只有"淡到多少"，**没有"什么时候开始淡"**：

- `barDimAlpha`（悬停前透明度，默认 45%）只决定淡到什么程度；
- `bar.js` 在横条**登场的那一帧**就挂上了 `qs-dim` —— 于是弹出立刻是半透明；
- `barIdleSec` 是"无操作后收起"，不是"渐隐延迟"。

所以设置页里那两个滑块都不是你以为的那个"渐隐时间"，配了自然没效果。

### 修复
新增配置 **`barDimDelayMs`（渐隐延迟，默认 1500 毫秒）**，并在设置 → 外观加了一个
「渐隐延迟」滑块（0 ~ 5 秒，0 = 立即变淡，保留旧行为）。
横条弹出时先按整体不透明度显示，过了这个延迟才平滑淡到「悬停前透明度」。

## 修复后的完整表现

1. **弹出瞬间**：完全不透明（受「横条不透明度」控制，默认 100%）。
2. **保持 `渐隐延迟`**（默认 1.5 秒）：这段时间内一直清晰可见。
3. **延迟到点**：平滑过渡（约 0.22 秒缓动）淡到「悬停前透明度」（默认 45%）。
4. **鼠标移上来**：立刻平滑恢复到完全不透明（不等延迟）。
5. **鼠标移开**：重新计时，满 `渐隐延迟` 后再淡下去。
6. **展开「更多引擎」面板时**：保持不透明（你正在里面点东西）。
7. **「悬停前透明度」拉到 100%**：整套渐隐关闭，任何时候都不淡。
8. **「无操作自动收起」**（另一个设置）：到点后直接收起横条，与渐隐互不影响。

## 安装

便携版，无需安装。下载 `QuickSearch.exe` 覆盖原位置即可（旧配置不受影响；
老配置没有 `barDimDelayMs` 这个键时按默认 1.5 秒处理，升级即生效）。
