# Quick Search v1.5.0

**横条不再乱弹了，而且它学会了自己收起来；设置页也重新分了栏。**

---

## 一、修：「横条会莫名其妙地冒出来」（本版主修）

你的原话：

> 有时候横条会莫名其妙的出来，明明我只设置两种出来的方式，一种是选择了文字，一种是我按 control 加 c，但有时候可能是我误触了，但它还是会出来。

三处「兜底」在乱弹，全部收紧了：

| # | 老行为 | 为什么烦人 | 现在 |
|---|---|---|---|
| ① | 只要按了 Ctrl+C 就弹，**不等剪贴板** | Ctrl+C 在终端里是「中断」、在对话框里是「复制一个空选区」、手滑碰一下也会弹一条装着**上一次剪贴板内容**的横条 | 先等剪贴板**真的变了**（最多等 0.5 秒，一落地就弹）才弹；没复制到就什么都不做 |
| ② | 拖选取不到文字时**也弹一条空横条**（r89"任何情况都要弹"的兜底） | 拖窗口、拖滚动条、拖画布、拖文件图标都算"在客户区拖了一下"，三条取词通道全失败照样弹 | **没拿到文字就不弹**。自绘界面（游戏、部分 Electron/Qt）取不到词的，可以在「通用 → 触发 → 没取到文字就不弹」里关掉这条 |
| ③ | 取词要几百毫秒，这期间你点了别处 / 按了 Esc，它读完**照样弹** | 你已经去干别的了，横条突然冒出来 —— 最像"鬼上身"的一种 | 记住了"你收过条"，取词结果回来时发现你已经收过 → 这一次作废 |

## 二、新增：横条会自己收起来

你要的两条，都在「通用 → 触发」里，滑块可调，**0 = 不收起**：

- **鼠标移远就收起**（默认 400 px）：「如果鼠标移动了很大的一个范围，那么就说明这个横条是不会需要的」。判据是**指针到横条矩形**的距离 —— 不是离弹出点多远。所以横跨半屏去点它、贴着面板边缘拖动缩放，都不会被误收。
- **无操作自动收起**（默认 5 秒）：「横条出来了 5 秒，但 5 秒没有任何的操作，那么就消失」。

三种情况**不算**「没操作」，不会被收走：

1. 指针正搁在横条上（哪怕一动不动）—— 你正指着要点的按钮；
2. 「更多引擎」面板开着 —— 你在翻目录；
3. 右键菜单开着。

## 三、设置页重新分栏

你的原话：

> 关于横条的外观的相关设置，你要单独列一栏来设置，现在是放在通用里面，这不好。还有黑名单、白名单也是这样。Ai 抠图也是。

原来「通用」页塞了 7 张卡片（触发 / 主题 / 横条外观 / 预览 / 应用范围 / 系统 / AI 抠图），找个开关要滚半天。现在：

| 分栏 | 内容 |
|---|---|
| **通用** | 触发（含上面两个新滑块）、界面主题（设置窗口与横条共用）、系统 |
| **外观** 🎨 | 横条样式（默认 / 磨砂 / 液态玻璃）、玻璃预设与六项参数、跟随鼠标、图标大小、内边距、不透明度、悬停前淡度、动画、阴影 + **实时预览** |
| **范围** 🚫 | 黑名单 / 白名单（在哪些软件里不弹 / 只在哪里弹） |
| **抠图** ✂️ | AI 抠图开关、模型选择与下载 |

## 其他
