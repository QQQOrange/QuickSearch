# Quick Search v1.5.1

**「外观」页换了顺序：界面主题 → 横条预览 → 横条外观。**

---

## 改了什么

你的原话：

> 在外观面板里面，把预览应该放在最上面，不应该放最下面，放在最下面就不能够有一种即时的观察了。界面主题这一栏应该也放在外观，所以外观这一栏它的布局应该先是界面主题，然后是横条预览，然后再是横条外观的设置。

`外观` 页现在的顺序（从上到下）：

| # | 卡片 | 里面有什么 |
|---|---|---|
| 1 | **界面主题** | 跟随系统 / 亮色 / 暗色、圆角（设置窗口与横条共用） |
| 2 | **横条预览** | 实时的横条长什么样、在深色背景上预览 |
| 3 | **横条外观** | 横条样式（默认 / 磨砂 / 液态玻璃）、玻璃预设与六项参数、跟随鼠标、图标大小、内边距、不透明度、悬停前淡度、动画、阴影 |

主题放最前，是因为它一变，下面那条预览整条跟着换皮；预览放参数前面，拖滑块时它就在上面的视野里。

`通用` 页现在只剩 **触发**（选中/Ctrl+C、出现延迟、无操作自动收起、鼠标移远就收起、没取到文字就不弹）和 **系统**（开机自启、以管理员身份运行）。
