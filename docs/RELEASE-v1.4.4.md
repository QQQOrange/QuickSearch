# Quick Search v1.4.4

**「更多引擎」的二级目录也改成胶囊了 —— 三层目录，一个口味。**

---

## 这次改了什么

### 二级（中类）从下拉菜单改成平铺胶囊

你的原话：

> 最好中类也作为胶囊式的，点击中类后，才会展开中类下面的小类。

以前面板的三层目录是**两种形态**：一级大类、三级小类都是平铺胶囊，唯独二级（搜索引擎 / 直达网页 / 软件搜索 / 软件直达）还是「一个胶囊 + 下拉菜单」。

可中类一个大类底下也就两三个，全铺开也只有一行 —— 却还要多点一次「展开」、在菜单里找、点完菜单又收起来。和大类、小类的操作口径也不一致。

现在三级一个口径：

| 层级 | 形态 | 什么时候出现 |
|---|---|---|
| 一级（大类） | 平铺胶囊：全部引擎 / 网页引擎 / 软件引擎 / 快捷键引擎 | 一直显示 |
| 二级（中类） | **平铺胶囊**：全部中类 / 网页搜索引擎 / 网页直达引擎 | 选了大类才出现 |
| 三级（小类） | 平铺胶囊（紧凑款）：全部 / 网页 / AI 工具 / 知识 / 开发 … | **选了中类才出现** |

点谁看谁，「全部中类」恢复全量；取消中类，下面那行小类也跟着收起来。

设置页「引擎库」的中类本来就是平铺胶囊，这次之后两边长得、用起来都一致了。

### 顺手修掉：点了中类 / 小类，胶囊不高亮

这次改二级时查出来的一个**老问题**（三级从上一版起就是胶囊，一直藏着没被发现）：

面板滚动时那个「高亮当前分类」的逻辑，会把**所有**目录按钮按分类名重画一遍。而二、三级胶囊是**筛子**、身上没有分类名，于是每滚一次都被判成「不亮」—— 点完选中的那颗**立刻被熄掉**，界面看着像「根本没点上」。

现在筛选行一律不归它管：点谁谁亮，滚到哪儿都亮着。

### 测试套件第一次全绿

这次为了验证改动，发现 `tools/test-ui.js` **从来没跑完过**：图标编辑器那两段用例因为配置里没开「AI 抠图」总开关（r80 起「编辑图标」按钮受它控制），一行按钮都不渲染，先 FAIL 再抛异常，把后面**一整半测试**（横条、面板目录、备份、收藏夹……）全带停了 —— 表现出来就是「151/154，后面根本没跑」。

修好的过期断言：

- `baseConf` 补上 `aiMattingEnable: true`（图标编辑器用例的前提）；
- 「容差滑块」两条断言删掉（r80 起那个滑块已从产品里删除，元素都没了）；
- `icon_remove_bg` 的 `tolerance` 字段 → 改成断言 `params` 六件套（maskThreshold 128 / feather 1 / fg 240 / bg 15）；
- 「只留下 github 命中」改成走产品自己的匹配口径（**Copilot 的别名里就有 "Github Copilot"**，按别名搜到它是设计如此，不是 bug）；
- 「自定义引擎出现在全部引擎」先点一下「全部引擎」分组（r61 起列表选了分组才有内容）。

现在 **484 / 484 全过**，并补了两条回归断言：选中的中类 / 小类胶囊必须保持高亮。
